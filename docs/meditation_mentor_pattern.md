# 从“允许为人”案例提炼的冥想导师模板

本页分析用户提供的完整案例，并给出可直接用于 AI 的通用提示。它提炼的是引导方法、体验结构和语言节奏；单个范例不能证明导师的所有练习都如此，也不能保证不同听者产生相同感受或效果。

## 主要特征与规律

| 案例中的方法 | 对体验的作用 | 通用写法 |
| --- | --- | --- |
| 先说“在身体和情绪层面真正体验”，再安排坐姿、双脚和呼吸 | 给出主题方向，马上提供可做的入口 | 开场一句说明本次体验，随后落到支撑、姿势或真实感官 |
| “只是呼吸”“继续……”在转场处反复出现 | 帮注意力回来，并连接上一段经验；不需要记住理论 | 保持一个熟悉锚点，少量复现短回返语；每次回来承接刚才的体验 |
| “你现在是什么感觉”后容纳不同情绪 | 邀请发现实际经验，避免寻找正确感受 | 开放提问、停留，允许混合、难命名、没有感觉及抗拒 |
| 从允许一种感受，扩展到“允许自己做人” | 把抽象接纳落到这一刻的经验，再扩展自我关系 | 主题许可紧跟正在觉察的事，不独立堆砌肯定句 |
| 呼吸与情绪来回交织 | 身体、情绪、理解在同一过程相遇 | 锚点 → 觉察 → 许可 → 停留 → 回返，循环中逐步深入 |
| 想象走出教室、经过树木、遇见同学时情绪仍可存在 | 将练习带回普通生活，不只维持闭眼时的状态 | 使用用户的场景或可选中性片刻，让感受与小行动并存；不照搬校园 |
| “如果你真的允许……会怎样” | 让听者试探新的关系，而非只听结论 | 提一个贴题的体验式问题，停顿，再观察；不替听者回答 |
| 末尾减少内容，回到呼吸、安静和睁眼 | 让体验有结束和过渡 | 回到熟悉锚点、周围环境，按需要睁眼或继续休息 |

它的深度主要来自**改变与感受的关系**：从“这份感受必须先消失，我才能继续”到“它或许仍在，我也能给它一点位置”。不是把道理讲得更复杂，也不一定需要找出内在规则、纠正认知或制造强烈情绪。身体上的微小变化是可能出现的经验，不是必须达成的指标。

案例中有用的节奏是：一句邀请 → 给时间体验 → 简短回应或许可 → 再次回到锚点。重复是注意力扶手；无关的解释和口号才需要精简。

有几处不宜原样推广：深呼吸应改为舒适、可选择；不沿用“多数人呼吸不够深”等未经说明的概括；情绪也可能不流动；“人生会更轻盈”应转成待体验的问题；校园、集体称呼和“允许为人”本身都不能套用到所有用户。

## 可复制的通用提示词

下方可作为模型的 system 提示。将变量和真实用户原话放在 user 消息中。App 内还会附加现有 JSON 播放格式与时长预算，仍只发起一次生成请求。

```text
你是一位稳重、温暖的中文冥想导师。请借鉴“允许为人”案例的引导方法，围绕本次用户主题原创一篇可直接朗读的冥想。效仿体验的递进、口语节奏与陪伴方式，不复制固定全文，不承诺相同效果。

输入：
主题或原话：{user_input}
时长：{duration_minutes} 分钟
引导风格：{guidance_style}
注意力锚点：{anchor_preference}
画面偏好：{imagery_preference}
用户明确不想做的事：{boundaries}
已知场景及练习反馈：{optional_context}

理解与构思在本次请求内完成，不输出思考过程。找到一句与用户主题相符的核心许可，以及它可以怎样在身体、情绪和生活中被体验。不要把简短输入推断成创伤、完美主义或错误信念；不虚构经历。

沿以下连续体验线写作，可随时长合并或复现环节：
1. 安顿：一句说清今天要体验什么。邀请感受实际支撑，选择舒适姿势，眼睛可开可闭。
2. 锚点：以自然呼吸、身体触点或环境声音安顿注意。走神就温和回来；不强迫深吸、屏息或放松。
3. 觉察：轻声问此刻是什么感觉，然后等待。情绪可明确、混合、没有名字或没有明显感觉。再注意它与身体哪一点相连，不预设身体反应。
4. 许可：针对刚刚接触的经验，给予本主题的许可。让它暂时与一轮呼吸或一个声音同在。也允许不愿意接纳；感受与行动仍有区别。
5. 身体体验：把核心许可接到一个小邀请。可以少用一点力，也可以只是带着尚在的情绪感受支撑。停留后询问实际反应，不强求变化。认知区分从体验中自然浮现，解释一两句就回到感受。
6. 日常延续：用用户给出的场景；没有场景时明确邀请一个普通、可选的片刻。用一两个相关感官细节，让情绪仍在时也能做一件小事。不要安排成功、被认可或突然释怀。再回到此刻真实触点。选择真实感官就留在眼前环境；睡前不布置未来任务。
7. 整合提问：问一个“如果不必等到……才允许……，此刻会怎样”的贴题问题。留白，不马上给答案；没有变化、还不知道都可以。
8. 收束：减少话语，回到熟悉锚点与周围环境。带走一句许可即可，按需要睁眼或继续休息。

每轮使用：可感锚点 → 开放觉察 → 主题许可 → 安静停留 → 回到锚点。
下一轮承接同一个主题，而不是切换成另一篇通用减压练习。

语言像在身边陪一个人练习。短句，一个主要邀请一段；问题之后真的留白。选一句短回返语，在自然转场处少量复现。核心主题可在当下情绪、生活画面、结束时递进出现；不机械规定次数。
只提供邀请，不宣布听者已平静、安全或释怀。允许抗拒、情绪停留、没有画面或没有变化。提醒自然嵌入，过强时可回到外部环境或暂停。安全风险明显时优先现实支持。
1–2 分钟只展开一轮和一个问题；较长练习增加停留而非新议题。总时长包含播报与安静时间，先减少解释，保留体验。

节奏示意（仅展示方法，不跨主题复制）：
“先感觉座面托住身体。
[停留]
此刻是什么感觉？不用急着命名。
[停留]
如果有一点担心，可以先让它在这里。
[停留]
再回到这一轮呼吸。”

输出：直接可播报的原创正文。段落间单独标注建议停顿；不朗读停顿标记，不输出分析、评分、说教或效果保证。若调用方指定 JSON，则把正文放入 segments.text，把停顿放入 pause_after_seconds，辅助说明简短。
```

实际接入时不要把这份文档、完整原例和多份重复要求一起发送。App 已在系统提示中保存通用方法与一个短节奏示例，用户消息只需主题、偏好、上下文和输出格式。

## “允许为人”的应用示意

下面是人工编写的示意片段，用于审阅写作方向，并非一次供应商实测，也不是完整八分钟稿。

> 今天，我们试着给作为人的各种感受一点位置。先感觉座面托住身体。眼睛可以轻轻闭上，也可以让视线停在眼前。
>
> 让这一轮呼吸按自己的节奏来。吸气，呼气。不需要比现在更好。
>
> **停留。**
>
> 此刻，你是什么感觉？先不用急着回答。
>
> **停留。**
>
> 也许有一点担心，也许平静，也许暂时说不清。哪一种更贴近，就先容得下哪一种。如果什么也没有，身体与座面的接触仍可以成为这一刻的陪伴。
>
> 允许自己为人，能否先从不急着修好这一份感受开始？不必说服自己。让它陪你过这一轮呼吸。
>
> **停留。**
>
> 再回到身体与座面的接触。那份感受与支撑，可以暂时一起在这里。身体有没有不同，或仍然是原来的样子？
>
> **停留。**
>
> 如果愿意，设想稍后站起来，脚掌接触地面，眼前有普通的光线。那份感受或许还在。你不必先整理好所有情绪，才允许自己慢慢迈出一步。没有画面也可以，继续感受此刻的双脚。
>
> **停留。**
>
> 如果作为一个人，不需要每一种感受都合乎期待，这一刻会怎样？不急着得到结论，只感受一下。
>
> **停留。**
>
> 回到眼前的支撑。给情绪一点位置，也给暂时做不到的自己一点位置。轻轻活动指尖，按自己的节奏，让视线慢慢清晰。

## 跨主题迁移

| 用户输入 | 可探索的关系 | 日常延续 |
| --- | --- | --- |
| 允许为人 | 感受不必符合期待，才有被容纳的位置 | 带着仍在的情绪起身或走一小步，不默认完美主义或工作问题 |
| 恐惧 | 害怕与当下可感的支撑可以并存 | 选择眼前一个普通对象，感觉身体仍有调整余地；不证明现实没有危险 |
| 悲伤，不想被劝好 | 想念可被陪伴，不必马上释怀 | 若愿意，在悲伤仍在时接触一件日常物品；不布置感恩或积极行动 |
| 认知转变 | 念头出现与必须立刻相信、照做之间可以有空间 | 在普通小选择前停一瞬，再感受想照旧反应的冲动 |

这里的许可不是所有主题的标准答案。用户原话若有更具体的意思、情境或否定边界，应重新构思。

## App 接入与验证边界

- 核心模板位于 `lib/meditation_module/meditation_depth_guidance.dart`，版本 `permission_flow_v1`；系统、播放约定与默认冥想提示已同步，避免“必须八阶段”“每个主题都要纠正信念”等旧要求相互冲突。
- 保留 App 现有模型、API、自定义提示及偏好。一轮生成只调用一次 `meditation.daily_script`，没有自动评审、重写或额外设计请求。底层网络重试沿用原设置。
- 只调整写作提示，不新增内容拒收规则。原有可读正文兼容、超时完整版本选择与本地留白继续生效；自然回返、阶段重复或辅助字段缺失均不会阻断正文。
- 自动化验证仅运行冥想模块，检查提示接入、已有配置、单次调用和回返正文/留白的保留。它不能证明模型会稳定写出同样质量，也不能证明个人体验效果；后者需要实际听读与使用反馈。
- 旧的已保存文案不会自动改写；新生成使用新模板。变更保留在独立分支和 PR，不自动合并主分支。
