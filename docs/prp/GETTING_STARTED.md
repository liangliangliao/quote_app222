# PRP：安装后从哪里开始

适用于 PRP v1.1.0 / App 1.1.0（构建号 15）。插件和 AI 均不会因为安装更新而自动开启，已有开关与教训保留。

## 先完成一条教训

1. 打开底部“设置”，在首页点“PRP 插件 · 失败成长”。旧路径“设置 → 功能模块配置 → PRP”也保留。
2. 开启插件，保留“失败与完美主义”调用点。AI 默认关闭，离线也能完成。
3. 点“开始一次复盘”，会进入完整会话：缓一缓 → 对账 → 有效/无效 → 预警与如果—那么 → 长按 3 秒盖印 → 拉远。
4. 结束后，在同一设置页的“我的教训手册”里查看刚才的教训。没有盖印的草稿不会进入回访或首页。

主动开始不受自动提议每日额度限制，仍遵守静默时段、静音、安全退场和总/分开关。不能开始时页面会提示查看诊断，不会无响应。

## 为什么总开关已开启，火种和首页看起来仍一样

总开关开启不会生成示例教训，也不会自动开启所有调用点。设置页会显示盖印数量和当前未满足的条件。

| 场景 | 触发方式 |
| --- | --- |
| 美丽的敌人 | 对一条字据明确确认“没做到”，才提议复盘；没有记录不等于没做 |
| 行为追踪 | 将预设明确标记未完成，才提议会话；已有教训在下一次每日确认处回访 |
| 失败与完美主义 | “我刚失败了：3P急救”及“直接练：失败复盘”入口 |
| 火种 | 开启“火种”调用点，有盖印教训后，在“回溯”的候选步骤出现其有效做法；清单页不增加失败提示 |
| 名言首页 | 开启“名人名言首页”调用点、“自己的名言混入首页”和回访，并在教训上逐条同意；点“换一条”按每日额度混入 |

自己的名言默认每日最多一次，至少间隔 24 小时，并受静默/静音影响；普通名言样式和收藏功能保留。火种中途退出继续静默，不会被算作失败。

## 确认安装包

使用 `feature/prp-plugin` 分支的 **Build Android APK** 构建产物。PRP 设置里应有“开始一次复盘”、痛感对照/潮汐光迹/废稿短句快捷入口，以及 `PRP v1.1.0 · 构建 …`，其中构建号前 8 位应与 APK 附带的 `build-info.json` 中 `source_sha` 一致。完整源码 ZIP 可能另含后续文档和验收脚本提交，应用源码对应关系见审计。

本次可安装包来自[构建 42215899915](https://github.com/liangliangliao/quote_app222/actions/runs/42215899915)，源码标识 `5ce4d70d`，版本 `1.1.0（15）`。下载该运行中的 `quote-app-5ce4d70dfc97-run1688` 产物并安装其中 APK。设备验收的应用源码与发布包一致；后续仅验收脚本及文档修改不会重发 APK，逐项 Git 对象对照见审计的溯源记录。

APK 附带 `build-info.json`、`release-verification.json` 和 `SHA256SUMS`。构建核对源码树、包名、签名、ABI 和版本号。覆盖安装请保留原应用数据，不需要卸载清库。

## 新增可选功能

| 功能 | 操作与预期 |
| --- | --- |
| 痛感对照 | 点设置顶部“痛感对照”并确认开启；先记具体事情、强度和预计天数，事情过去后补记实际，看到两者曲线和倍数。实际为 0 的维度不算倍数 |
| 潮汐光迹 | 点顶部快捷入口并开启；按住光点时散开，松手后回落。不计分、不产生失败事件 |
| 废稿短句 | 点顶部快捷入口并开启；浏览原创练习句，可复制或起草自己的复盘。不会冒充名人引言或自动盖印 |
| 原生教训 | 开启“原生闹钟显示教训”，保留行为追踪与回访开关；先为对应行为生成并盖印一条教训。下次当天预设闹钟表单或浮层显示该教训，受每日回访额度、静默和静音限制 |
| 原生自己的声音 | 先开“自己的声音”，在手册给已盖印教训录制一段第三人称提示，例如“小林，先打开书读 1 页”。再单独开“原生闹钟播放自己的提示”；到点播放该段本地录音，最多 15 秒。插件关闭立即停止 PRP 声音 |
| 采纳与验证 | 回访里点“这次试试”，只是记录采纳。实际尝试后再报有帮助/没挡住；不反馈保持未验证。多次没挡住可改一版，旧版历史保留 |
| 转成字据 | 在手册选一条已盖印教训，点“确认后转成字据”选择期限；敌人模块须开启，默认无赌注，重复点击复用已建字据 |
| 本地观察 | 设置 → 我的本地观察，查看最近 30 天的步骤、暂停、盖印、采纳、明确结果、复犯间隔和情绪配对。数据只在本机计算 |

收到提醒、点击已收到、没有打卡、火种中途退出都不等于失败。可选功能全部默认关闭；关闭插件保留数据，在设置里仍可查看、导出或二次确认清除，清除包括 PRP 录音文件。

原生提示需要先在行为追踪设置一个已启用的预设闹钟，并为对应行为盖印教训。浮层沿用应用已有的悬浮窗权限，完整表单沿用现有闹钟流程。设备不支持离线听写时，可以直接输入文字完成同一套复盘。
