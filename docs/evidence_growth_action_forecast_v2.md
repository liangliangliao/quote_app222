# 行动预测 v2：证据、解释、行动与现实验证

本次升级位于发现之旅／六模块成长证据／行动发生可能性，基于 PR #161 的 `codex/growth-v27-journeys`。目标是让预测可定义、可解释、可核验、可修正。代码和模拟测试不构成真实行为预测准确率的证明。

## 审查结果与实现

| 原有问题 | 实现后的行为 |
| --- | --- |
| 行动描述和模型提炼事件可能不一致 | 用户确认可观察的达成标准、观察窗口；首轮、综合、情景模拟、复盘共享同一个冻结事件 |
| 无关行动或不同模型混合校准 | 必须明确同类情境组，事件、窗口、行动模式和模型版本匹配；旧数据继续可读但不进入 v2 校准 |
| 多次修订可能重复计数 | 一个真实行动对应一个 trial，只取最新事前预测；最新未观察时不会回退使用旧的已标记记录 |
| 拟合后的好看分数缺乏独立验证 | 按时间留出验证；训练结果必须早于验证行动的预测时间；校准未改善就不用 |
| 理论选项被当作等距分数或通用权重 | 保留各理论构念；共享因素只使用一次；个人关联模型使用已确认类别的独热编码，不用预填置信度作权重 |
| 模型提出的阻碍被反复计为已观察弱点 | 复盘时由用户明确标记实际出现的因素，才形成再次发生的观察依据 |
| 建议被立即当作现实变化并重新预测 | 先记录真正落实的变化、自己的理解与态度变化依据，再确认问卷；无输入变化禁止重复付费预测 |
| 中间网络失败导致已有分析丢失 | 保存已完成的 LLM/JEV 阶段与错误；联合链路未完成不显示正式最终概率，允许重试 |
| 缺少可追溯的学习报告 | 八部分报告及可复制 Markdown：事件、证据、关系、原因假设与实验、权重与校准、误差、复盘、方法来源 |
| 缺少同情境参照 | 独立的世界人群／指定人物入口、资料核验、假设敏感性、报告与历史；不混入自己的校准历史 |

## 方法与边界

LLM 与 JEV 首轮并发且互不读取对方结论；LLM 随后综合已确认的理论因素、结构规则和首轮结果；JEV 最后独立核验候选解释、深层机制、可行性、同事件条件变化和下一步决策。终裁概率不与 LLM 数字机械平均。不同阶段共享信息，因此阶段判断跨度不是独立投票或统计置信区间。

每个原因候选包含观察依据、机制、维持条件、替代解释、反证、可证伪观察、理论学习、信念检验、最小行动、If-Then、成本风险及停止规则。JEV 的支持度仍是模型判断，不能证明因果或人格。优先建议综合证据、可行性与成本；不会单按最高模拟概率排序。较长候选的 JEV 核验采用明确标注的节选，报告提示其核验范围；用户事实、事件标准和模拟变化本身不因这个压缩步骤被改写。

循环是：预测 → 核实原因假设 → 理解理论 → 记录真实条件与态度变化 → 用户确认后重预测 → 实际行动 → 观察与联合复盘。目标是完成可行的下一步并学习，不是反复生成更乐观的分数。改变成功标准或行动时间属于新行动；停止、改目标、取消也可以是合理结果。

### 个人校准

- 只纳入同事件、同情境组、同模式、同模型签名的 v2 真实记录；排除假设模拟、旧版、未观察、取消、结果早于预测、未来记录、重复修订和缺失估计。
- 达到 60 次独立可比记录、正反结果各 10 次才尝试。后 30% 为时间留出集；训练至少 40 次；训练和留出集分别至少包含每类 3 次。
- 使用带正则的逻辑校准 `sigmoid(a + b × logit(p))`，收缩到恒等变换，斜率非负。留出 Brier 至少改善 0.002，且对数损失改善，才使用截至当前已知样本重新拟合的校准值。
- 这些数值是工程门槛，不是文献承诺的充分样本量或显著性检验。报告仍称“个人校准试用”，没有宣称已具备普遍准确率。
- 展示真实配对记录的原始／最终 Brier、对数损失、平均预测、实际比例和五组可靠性汇总。这些历史汇总与本次校准的留出评估分别标注。
- 实际观察时间与录入时间分开；补记时可选择当时确认结果的时间。部分完成只有明确回答冻结主事件是否达成才进入二元评价。真实事件已发生后作出的预测不能因为后来才录入结果而成为有效前瞻样本。

### 个人因素关联

至少 120 次独立可比记录、正反各 20 次，训练至少 80 次，单类别训练出现至少 15 次，特征数不超过训练样本数的十分之一。正则化逻辑模型只使用已确认的类别；未知与未回答不推算负分。按时间留出，并分别与原始模型和训练基准率比较 Brier／对数损失，双方均改善才展示探索性关联系数与交叉估计。

这些系数描述所记录条件下的关联，不是跨人通用权重、唯一根因、已识别的因果效应或干预效益。它不替代主预测，也不把多个干预增益相加。

### 参照人物与全球人群

外部情境、行为标准与观察窗口固定；参照者自己的能力、习惯、态度可以不同。世界模式必须明确参考人群，输出仅是模型情景粗估，没有代表性抽样就不能称为全球实际发生率。

人物模式支持公众人物、熟悉的人或虚构角色。公众人物可检索中文／英文百科，用户选择并确认身份；也可输入有依据的行为记录。保留资料原文、链接、检索时间、引用段及来源类型。只有原文中确实存在的引用才能标记为有资料关联；模型生成的经历、性格解释或不存在的引文保持为假设。来源关联并不自动证明描述真实或与当前行为相关，还需要 JEV 评估证据质量。

只有身份确认、有可追溯资料、JEV 认为足以作粗估时才显示人物概率。仅有姓名或材料不足时保留分析与待补信息，抑制数字。不能仅凭人物声望、性格印象或一篇传记作“精确预测”。所有参照记录单独存储，最多保留 30 条，可清空；自己的行动历史最多保留 500 个预测快照。

## 数据与兼容性

继续使用现有设置表，无数据库迁移。自己的历史仍使用 `action_prediction_history_v1`；v2 记录含 `science_version`、`event_contract`、`trial_id`、`parent_prediction_id`、`input_fingerprint`、`comparison_key`、`model_signature`、阶段状态及 `scientific_report`。观察、修订前结果审计、用户复盘、LLM 复盘和 JEV 复核均与事前预测分开保存，不覆盖原概率。参照历史使用 `action_reference_forecasts_v1`。密钥不保存到这些报告。

## 验证与后续实证

新增自动化覆盖时间泄漏、取消和部分结果、重复修订、校准接受／拒绝、类别关联门槛、指标、模型输出边界、来源引用核验、同名人物消歧、完整预测链路及部分失败、重复调用预检、参照链路与隔离存储、复盘分歧、窄屏页面。网络模型使用可控的 HTTP／AI 替身，真实 DAO 持久化使用内存 SQLite；不使用伪造测试证明预测准确。

新增测试纳入 Evidence Growth CI。现有模块全部测试、严格分析、原生通知测试与 API 分析作为回归门槛；Android Release 由现有 PR 分支交付工作流编译。

实际准确率、跨人群外部有效性、干预效果、用户态度和行动是否改善，仍须持续收集前瞻性真实结果进行评估。复杂因素之间的因果权重、代表性全球人群数据和全面可靠的人物生活史，并非 LLM 加上结构化输出就能获得。
