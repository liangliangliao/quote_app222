# 按目的选概念、用相关案例分析与移除应用输出额度（v12）

本轮处理用户实际反馈的“在隆冬之中，我终于在自己内心发现了一个不可战胜的夏天”，并继续用用户提供的“持志如心痛……若只死死守着，恐于工夫上又发病”检查类属、内容追溯和含义范围。两段引文的版本与出处均未外部核定。

## 分析方式的修正

1. 先确定当前理解目的与考量，说明核心概念的选取理由，区分意象、所指的经验/能力/认识/价值概念及必要中介。用户可以修改本次考量；修改和浏览不会自动调用模型。
2. 不再接受以“内在心理资源的隐喻性表达情形”及其措辞组合代替所谈概念的类属树。下位须保留上位共同规定并新增明确限定。反例须说明概念的适用边界，不能只是删改句子或“单独说这个词不符合语境”。这些本地检查只识别部分结构与常见退化形式，不能证明全部语义正确。
3. 先按本次目的寻找共同规定、决定性差异和比较尺度。必要时明示经验论域中的范围概念，并用 `core_id` 回指原核心概念；例如可用同一生活经历论域考察逆境、保持力量与自我认识的关系。这是本次分析的范围投影，不把处境、能力、认识这三类概念偷换为同一种事物。范围判准须保留核心概念的关键限定，不能删除条件来制造交叠。离线案例区分当前外在逆境与此前受挫后的恢复；一般顺利处境中的行动不因此就算韧性。
4. 没有返回含义圈表示本次生成未完成，不断言概念没有联系。§9 及判断力的讨论不等于任意两概念必有外延交集，更不证明因果；几何仍须符合明示的成员判准和关系。无法排成一致全局圆图时保留对应的局部范围图。

## 相关教学案例

格言或隐喻不足以直接演示概念、直观内容或某种根据时，允许在**同一次生成**中给出核心意义高度对应的教学案例，然后分析它。不是从库中自动取用其他私人记录，也不额外发起案例生成请求。

`aligned_cases` 保存独立身份、标题、完整具体情境、分析目的、逐项意义对应和边界。每项对应同时定位原句短摘与案例细节，并说明保留了什么。客户端检查两边摘录确实存在、身份不冲突、边界不空；这些检查不等于证明案例在哲学上完全贴合，仍需人工判断。

页面在图前显示案例完整情境和目的，并可展开查看对应与边界。案例事件须标为模拟，不归给作者或用户。案例身份与内容进入展开上下文，不能在分支扩展时静默改写；新概念仍须连回已有分支。比较派生的阅读概念也追溯到案例与原材料的对应，避免漏掉案例支持的自然核心概念。

离线演示模型用“求职受挫但仍继续练习、交流和申请”的情境说明逆境、内在力量与认识到这种力量。它只演示一种有边界的读法，不是作者经历、实际模型回答或普遍心理规律的证明。

## 绘图及相关模块

- 概念树同时展示明确区分的实线类属和虚线内容追溯。通过必要概念中介返回具体情境，避免中介仅存在于另一页而总览出现断链。
- 含义圈画实际区域；长标题在本圈内寻找可读位置，避免多个标题叠成一行。范围节点可以返回核心概念详情，命名交集继续使用原概念身份。
- 四重根据按当前材料选用，不强制凑齐。季节意象或“内心”不直接成为时间/空间事实；“原句措辞→AI解释”不冒充认识根据。时间关系须区分先后、同时与期间，期间不画成先后箭头。
- 比较服务的外层 JSON 协议更新到语义图 v6，避免外层仍要求旧协议而覆盖内部分析要求；保留目的、案例与概念选取信息。
- 共享阅读、发现之旅与认识注释指引，以及电影解读说明，均要求按材料适配、单独标注教学对照。日记逐字定位原记录，电影场景仍须对应提供的简介，案例不改写为真实输入。
- 缺失直观链的显式完整概念树结果保持未完成状态，不能写入合格缓存。补全后按实际合并结构重新计算诊断，模型仅声称已修复不算修复。没有自动付费修复循环。

## 输出 Token 政策

依用户最新要求，**应用默认且始终不设置可选的输出 Token 上限**。旧全局 90000、任务额度、模块默认值与导入的旧值均不再作用于请求；设置页移除输出额度编辑，其他温度、超时、重试设置保留。

核查和修改统一文字/对话入口、OpenAI Responses、Azure、DeepSeek、OpenRouter、Eden AI、xGrok、Gemini，以及概念实践引擎、电影角色实验室、知行树远程知识、意志镜私有适配、证据研究和 Android 原生语音/转写纠错直连。语义流传输不再按旧 Token 额度换算字节截断。旧的 `maxTokens` 命名参数仅为调用兼容，不能恢复请求中的可选上限。

Claude Messages 是协议例外：[官方接口](https://platform.claude.com/docs/en/api/messages/create)要求 `max_tokens`。删除该字段会让接口失效，0 也不是无限生成。因此从同一服务的[模型元数据](https://platform.claude.com/docs/en/api/models/retrieve)读取该部署的最大能力并缓存；部分不提供元数据的部署仅对已知版本采用公开能力值，未知版本明确报错，不代填 2000 或其他任务额度，不通过反复付费生成探测容量。语义图请求仍使用流式接收。

模型与平台自身仍有上下文、输出能力、超时和账户限制。“不设置应用额度”不表示物理无限输出，也不保证实际消耗增加到模型最大值。保留本地缓存、批量分类、用户选择的请求次数及最多三次失败重试控制；移除旧估算 Token 总额对分类请求的阻断。模型实际返回的输入、输出、推理与缓存用量仍记录，未知用量仍显示未知。历史已应用额度与新请求的协议必填模型容量分别标注。

## 验证边界与使用

新增本地回环请求测试覆盖各服务的文字/对话与 Responses 请求，在遗留全局/任务设置仍存在时检查实际请求无可选额度；Claude 检查元数据只读一次、使用公布容量、流式解析与无付费探测。其余直连与原生请求另有静态核查。

新增离线概念/相关案例模型验证选取目的、自然概念、案例定位与模拟身份、类属/直观链、真实圈区域、长标题、原核心回指、展开的新旧关系、一次显式补全和比较派生。另覆盖 320px 与双倍字号及现有功能回归。真实页面截图来自 Flutter 测试渲染，标为离线教学模型。

手动哲学验收新增 **I：隆冬与夏天 · 目的、核心概念与相关案例**，保留 H（王阳明）。旧缓存不自动调用模型升级；对旧结果点击“按新版重新分析概念与连线”或相应生成按钮获取新结构。一次显式生成未完成时保留可用部分与旧成功缓存，不叠加自动补全。

**自动测试、数据协议和几何约束通过不等于真实 AI 分析合格。** 本轮没有使用用户密钥调用付费模型。实际 Azure 模型的原句忠实度、案例贴合程度、概念准确性及判断质量，仍须在设备上逐项人工检验，不能预标为通过。
