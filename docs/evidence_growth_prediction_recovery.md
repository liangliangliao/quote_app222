# 行动预测阶段恢复

截图中的两个状态都表示请求链没有全部完成，不能把保留下来的初步分数当作联合最终预测。仅凭旧截图不能区分手机网络、服务限流、鉴权与解析失败；新版保留安全的错误类别和 HTTP 状态供核对。

## 修复内容

- 移除初步分析、二次综合和参考预测的外层固定限时。统一 AI 服务已经限制每次 HTTP/流式请求并执行用户设置的重试；外层 120 秒会在内层重试尚未结束时提前放弃，且无法取消底层请求。继续尊重统一服务的请求与重试配置，没有追加隐藏的 LLM 重试。
- JEV 请求按问题数量和 64 KB 字节限制拆分。核心行动判断每批最多 16 个问题；通用参考/复盘超过 16 个问题时分批处理。每批传递同一完整事实，优先取得原成功标准对应的概率，不拆碎事实或降低目标。
- JEV 复核采用与行动初判相同的等待下限（45 秒），避免较重的复核仍被 30 秒截断。
- 二次 LLM 综合最多输出 3 条结论、2 条交互，缩减长 JSON 的必需字段。未知理论信息不编造因素或根因；没有问卷时可完成事件复核，而不会永久卡在 `NO_CONFIRMED_THEORY_FEEDBACK`。空对象、非法模式和不存在的因素仍不能通过校验。
- 成功阶段写入最多保留 8 个执行记录的本地日志；相同 DAO 的并发写入串行处理，防止两路独立初判相互覆盖。已保存的部分报告重新打开后，可以继续未完成步骤；旧报告也可从其保留的有效结果接续。
- 重试冻结原行动、成功标准、观察窗口、问卷与事实。阶段键包含原输入、模型/端点身份和上游有效判断；模型改变时重新计算受影响阶段。传输错误、缓存元数据不作为行为证据，不能单独触发新的综合分析。
- 缓存通过校验的 JEV 批次，失败批次不缓存；行动重试跨重启可恢复已完成的批次。再次超时或进入限流冷却时，仍保留同一请求的有效初判概率。
- “继续完成预测”接续原报告；主预测按钮对于同一行动、同一条件的部分报告同样接续。新的事实或行动理解启动新分析。结果产生后、报告被更新取代后均不能在旧报告上补预测。
- 完成接续后保存同一试次中的新预测快照；不覆盖旧分数，不重复创建独立试次，不把未完成估计纳入正式准确度。
- “同情境下，其他人会怎样”可只重试 JEV，保留人物身份、著作/资料、引用、LLM 分析和原比较条件，不重新联网搜索或生成一套新人物叙述。

## 失败反馈

报告区分 AI 初步分析、JEV 初判、LLM 综合和 JEV 复核，并显示超时、网络、401/403、400/422、429/529、服务错误或返回不完整等类别。复制诊断包含阶段、模型、有限的格式错误代码和 HTTP 状态，不包含密钥、原始服务错误体或原始 HTTP 请求。

阶段失败仍显示已取得的初步估计和来源；只有必需预测阶段都实际完成才显示最终估计。可选因素或复核明细缺失单独标记，不把它伪装成已经全部完成。

## 验证范围

使用独立 JEV wire 合同夹具验证有序 Score criteria、Choice 对象、Noul 概率等接口约束。回归覆盖每个失败位置、跨服务实例/应用重开接续、合法慢响应、限流保留、模型变化、空问卷、旧快照、无效 JSON/因素、参考人物恢复、已结束行动以及故障文本不泄露密钥。

没有使用用户设备的真实密钥发起付费模型请求。本轮验证的是流程正确性和恢复能力，不能据此宣称真实行为预测准确度已提高 10% 或所有服务请求必定成功；概率误差目标仍需独立现实结果验证。
