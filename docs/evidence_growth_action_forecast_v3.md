# 行动预测 v3：先评价重要性，再综合支持与阻碍

本次修复发现之旅／六模块证据成长中的自身行动预测、预测与学习报告，以及同情境指定人物预测。原实现把 JEV 最后一次输出直接当综合分数，没有可核对的数值化因素权重；分析又集中在负面候选，容易让次要低分主导结果。

## 评分变化

每项现在分别保存当前状态、支持度、行动相关重要性、权重、排序、依据和阻碍路径。LLM 与 JEV 独立判断重要性，问题是：**只把这一条件从有利改为不利，保持其余条件相同，会多大程度改变本次行动？** 不把“阻碍很强”等同于“因素很重要”。日常独立跑步的他人赞许可以低重要性；所需权限、时间、身体能力等确实必要的条件可以高重要性。

- 两个模型都返回有效重要性时取其均值；只有一个有效时使用该判断；都未返回则标为未评估，不伪造系数。
- 原理论共享的同一构念只给一个预算；通过原有增量价值筛选的行动特异条件单独计入。重要性归一化后形成因素权重，排序与当前支持分分开。
- 用户问卷仍是类别证据。问卷的 0～4 序位不进入加权计算，不假设选项之间等距；加权使用模型对该已确认状态的独立支持度判断，排除与已确认类别相反的评分。
- 未知状态不进入正负贡献。已评估的重要性中，有状态依据的占比用于描述证据覆盖，不能把未回答折算成负分。
- 有利、不利、利弊并存的占比表示各类因素分配到的权重，不是各类因素的实测因果贡献或发生率。

令 `Q = Σ(因素权重 × 模型支持度)`。Q 是诊断支持指数。最终原始估计使用一个透明、尚待实证验证的线性组合：因素指数预算为证据覆盖度，LLM 事件判断预算为 1，JEV 初判与复核共同分享预算 1。每项预算再乘 `1 / (1 + 4 × |该项判断 - Q|)`，归一化后综合。偏离显式因素证据的判断影响减小；初判、复核不会成为两个完整独立票。这个规则对偏高与偏低判断对称，不固定抬高分数，也不固定采用 85%。

重要且严重的事实性阻碍保留单独限制：重要性至少 0.75、当前支持度不高于 0.25、瓶颈判断至少 0.6，并且必须有用户确认或原始事实对应。此时采用 `1 - 重要性 × (1 - 支持度) × 瓶颈判断` 的工程上限；多个上限取最严格者，不反复相乘。去重前检查所有此类阻碍，避免被同构念的支持性条目遮住。对于明确的客观前提失败，JEV 硬阻断判断至少 0.85 且匹配有事实依据的现实约束时，再保留对应的更严格上限。次要因素不能施加这个限制，缺少资料或测量字段也不是客观阻断。

以上均是可审查的模型启发式，数值门槛和组合常数不是文献给出的通用行为系数，也不是已训练出的因果权重。后续仍应依据真实前瞻性结果评价和调整。

## 报告变化

默认展示：预测可能性、实际结果及对照、同类行动的命中率和概率误差、因素权重占比与排序、至多三个具体阻碍及原因。删除默认展开的理论说教、深层根因叙述、抽象假设清单和内部字段。进一步的诊断材料仍保留在原有折叠明细中。

准确度与本次发生分数分别展示。没有有效配对结果时写“准确度待验证”，不把 85% 预测解释成 85% 准确。命中率按 50% 的发生倾向阈值计算；概率误差同时保留 Brier，避免只用二元命中忽略概率质量。记录或纠正实际结果后立即刷新当前同类统计，取消、未观察等继续排除；原始预测分数、因素权重和事前解释保持不变。

继续采用原有个人校准门槛及时间留出验证，不混合不同事件、观察窗口、情境组和模型版本。新版通过模型签名中的 `contextual_factor_pool_v1` 与旧 JEV 终裁模型隔离。个人校准也不能抹掉本次有事实依据的关键前提限制；如校准后再次受到该限制，会单独记录，不能称最终受限值已经获得独立的校准验证。

## 指定人物变化

- 使用配置的 Grok 搜索工具时，明确检索相关著作、文章、访谈、公开思想及相似行为，寻找思想与实际行为不一致的证据。
- 没有原生联网搜索时，保留中英文百科回退，并加入有界的 Wikiquote 著作与观点引文集检索。仅接受规范姓名完全匹配的条目，区分引文集整理、联网摘要、用户资料与原始文本，保留来源。
- 输出“作品／观点 → 可能态度 → 本次行动”的简短迁移解释。作品名和引用必须对应实际提供的文本，无法核对的内容降为模型假设。思想不作为当前健康、资源、承诺或必然执行的事实。
- 对参照因素也分别评估重要性与当前支持度，综合 LLM、JEV 与因素证据。资料不足影响判断把握，不自动把事件发生概率压低；明确的必要条件限制仍保留。
- 参照结果继续使用独立历史，不进入本人校准。认识的人与私人观察不会送去公开人物检索。

长请求只拆分 typed 问题，保留冻结事件与来源。可选权重格式异常不会丢掉已返回的有效事件判断；未完成计算仍明确标记，不用固定概率兜底。

## JEV 接口与未完成阶段修复

新增重要性评分最初误用了对象形式的 `criteria`，会让实际 JEV 接口拒绝整个请求；人物支持评分存在同样问题。依据 [TypeSafe 官方接口](https://docs.typesafe.ai/api) 修正：Score 的等级必须是有序数组，Choice 的选项仍使用对象。新的测试桩按这一外部接口契约校验发送的 JSON，不再无条件接受错误请求格式。每个证据／瓶颈问题也写明所指因素，因为问题 ID 不参与模型推断。

- 行动初判与角色判断采用至少 45 秒的等待预算，明确区分 HTTP 校验、权限、超时、网络和响应解析错误。
- 初判核心问题也可分批；64 KB 是本地请求体安全限制，并非厂商的 token 上限。每批仍包含同一冻结事件和事实，不能以其他事件的分数替代缺失的主事件。
- 可选因素答案异常或后续角色批次失败，保留已经验证的事件分数和其他有效答案。重试复用相同输入的成功批次，不缓存失败或不完整答案；缓存按请求和密钥的摘要隔离，密钥不写入报告。
- 最终联合分数与初步估计分开保存。初判、LLM 综合或最终复核未完成时，显示已有估计并注明“仅 LLM”或“JEV 初判已完成”；初步记录不计入正式预测准确度。角色明细不完整不会清除已经完成的联合事件分数。
- 默认卡片提供重试入口，卡片与复制报告均显示失败阶段和具体恢复提示。旧的未完成记录也可以显示当时已经保存的原始估计。行动特异条件的英文定义不再冒充中文阻碍原因。

## 验证

新增回归覆盖低重要性强阻碍、重要必要条件失败、未核实假设不能施加前提限制、去重不得隐藏必要条件、未知不扣分、共享构念去重、排序与支持度分离、组合对称性、旧权重兼容、引用和作品名核对、人物加权完整链路、结果记录后的即时统计及取消后的排除。现有窄屏、完整链路、长请求、历史与校准测试继续覆盖。

模拟案例中，LLM 85%、JEV 初判 54%、复核 48%，主要因素有强支持而一项低重要性因素强阻碍时，综合约为 80%，不再直接采用更低的复核数字。这是规则回归案例；截图没有完整问卷和实际结果，不能据此声称复现了截图的真实概率或证明预测准确率提高。

## 查阅的方法资料

- [Ajzen，1991，计划行为理论](https://doi.org/10.1016/0749-5978(91)90020-T)：区分行为意向、控制条件及其前因，重要性须依具体行为判断。
- [Michie、van Stralen、West，2011，COM-B](https://doi.org/10.1186/1748-5908-6-42)：区分能力、机会与动机，帮助识别实际必要条件。
- [scikit-learn：概率校准](https://scikit-learn.org/stable/modules/calibration.html)：概率校准、可靠性汇总与概率误差指标；模型组合本身不构成校准证明。
- [Wikiquote API](https://en.wikiquote.org/w/api.php)：公开著作与观点线索的有界补充检索，不能代替原作全文核验。

资料支持理论分类和验证原则；v3 的具体工程评分方案仍须用真实结果检验。
