# 概念关系与增量展开修复 v10

对应 2026-11-03 用户的四张反馈截图。修复继续更新 PR #208；90000 仍是设置页中可修改的全局输出上限，本次不改用户的额度、模型、分类成本策略或重试设置。

## 已修复的具体问题

- 展开原先只提供焦点概念，解析器又只接受本次返回的节点，连接到旧节点的边会丢失。现在发送紧凑的原图身份表、来源及已有连接；解析时使用原有概念，接受“只返回新节点和连接旧节点的边”的增量。普通新 ID 在本地加分支前缀，并同时改写所有端点；原有身份和定义不能被改写。不再要求模型重复整图。
- 概念树和含义圈共用同一批节点及类型连线。新→旧、旧→新及新→新的关系都进入合并结果、保存缓存和重新打开后的画布。无连线回到焦点分支的新节点会隔离并报告具体问题；主动局部修复必须实际补上连接，不能仅声称 resolved。不自动付费重算。
- 语义协议 v4 增加 `meaning_links`，明确区分隐喻、对照、主谓规定、条件、因果主张、先后、偏好、类比和语境关联。外延的五种圈图仍按论域、成员判准绘制；文学或价值材料中有依据的非外延关系也会画出带标签的连线，不再退成几个互不相连的圆。五种外延图与整体关系图可同时阅读，新增的非外延节点不被局部外延图遮掉。
- 树图直接打开全图，并标明下位限定、中介、直观、隐喻或对照；不能因节点排在上方就称其为上位概念，也不能将隐喻指向称为下位类。长连接绕开中间节点，减少把远端连接误看为中间节点连接的问题。每条关系可查看含义和原文依据，节点详情可访问相连概念。
- 命题条件字段是 AI 的解释，未逐字出现在转述中不能据此断言“结论遗漏条件”。取消这一误报；保留对明确否定反转、量词或模态强化的检查。跨材料连线需要覆盖两端概念的来源。
- 同义改写、仅加“一个”等词或重复同一判准不能产生下位类；相同成员判准也不能声称有独有成员的真包含。这些明确错误在本地隔离并保留诊断，不靠更多 Token 掩盖。
- 比较提示词要求先分别解释原句，再按同一比较轴说明共同结构和决定性差异；区分文学意象与解释、欲求活动与对象、经验发现与偏好次序，不能仅用“都涉及内在”或“A没说B”作分析。部分阅读无效时仍保留其他有效命题与连线。点击重新比较同时清理旧版本回退缓存，避免重新打开同一旧结果。

## 版本与使用

生成提示词 v5、比较提示词 v8、共享认识论方法 v6，语义图版本 v4。任务预算按不含版本号的稳定任务身份保存，升级后继续使用原配置；分支默认输出 4000，用户可主动调整。

旧缓存保留并标明旧版，不会在升级、浏览或切换视图时调用 AI。旧结果原先就没有返回的连线，无法由客户端凭空恢复；需点击“按新版重新分析概念与连线”或“重新比较”。这会产生一次用户主动请求。

原六组人工验收保留，新增 G「隆冬与内在的夏天 · 欲求与虚无」，针对本次反馈检查隐喻、概念身份、关系类型和比较理由。仍由用户主动运行、逐项人工复核，不自动花费 Token，不把未复核结果算通过。
