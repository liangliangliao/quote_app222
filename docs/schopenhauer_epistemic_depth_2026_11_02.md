# 叔本华认识论落地二次校准（2026-11-02）

本次基于 main 的 `1baa2dea9b4bc1b046f77aab7a77e152e024a954` 开始，沿用现有认知风格（默认关闭）、原名言数据和首页艺术画框，不增加一级模块或数据库迁移。

## 核心发现

1. **哲学词汇出现 ≠ 认识论生效。** 原系统有“共同点 / 差异 / 根据”，但缺少完整的原句命题、抽象保留的规定、具体殊相、抽象遗漏与判断目的；AI 仍可能用主题词代替真正判断。
2. **含义圈 ≠ 任意语义关联图。** 现有关系图会在找到原句的两段文字后绘制集合，但文字定位并不能单独证实集合范围；普通隐喻、相似主题和因果陈述不应生成外延交叠。
3. **认识根据 ≠ 原因，原文引用 ≠ 现实证明。** 从名言逐字截取一句话只定位了作者的文字；它并不能证明生活中的普遍因果和心理解释。事件记录也必须标为“用户报告”。
4. **共相 / 殊相必须同时保留。** 当多个行为共享一种一般规定时，属于同一概念不意味着所有后果相同；关键区别取决于本次判断目的。
5. **抽象有压缩损失。** 具体情境中的行动方式、时间、资源、风险、相反实例可能被一般概念省略，不能因为叙述漂亮就忽略。

## 本次代码改动（不替换现有模块）

- `QuoteEpistemicPath` 为可选的结构化认识路径：`proposition` / `shared_feature` / `particular_differences` / `abstraction_loss` / `judgment_purpose` / `ground_limit` / `quote_excerpt` / `relation_mode`。
- 新一轮 AI 名言生成和主动概念分析输出上述路径；模型返回的 `quote_excerpt` 必须是原句逐字子串，否则清空。不伪称作者原意、外部审核或直观实证。
- 复用名言解读原有“概念”和“判断”页签，展示共相、殊相、抽象损失、判断目的和根据限度；仍采用渐进展开，不往画框内堆内容。
- 复用现有选文分析弹层，以结构化字段展示对应认识路径，兼容旧注释。
- 比较服务提高外延圆圈展示门槛：不仅要逐字出处定位，还要明确可命名的两个集合及直接量化的原句；达不到就降级为原句文字比较，不强行画集合圈。即使绘图仍属暂定解释。
- 原因、认识根据、行动动机分别判断；AI 只能输出分析所引用的材料，不得自行补写用户历史或虚构实证。

## 验收重点

1. 读一条新生成的尼采隐喻类名言，在“概念”页签看见“原句命题 / 共相 / 殊相 / 抽象遗漏”，关系应倾向 `analogy` 而不是声称集合包含或因果定律。
2. 在“判断”页签看见逐字依据及其限度，模型不能将引用名言当作现实因果已经证实。
3. 旧名言、旧缓存、关闭认知模式时的原始列表/画框应与之前一样可读。
4. 以两条讨论幸福的名言进行比较，不能仅因都有“幸福”而出现集合相交的科学结论；明确定义的集合例句仍可显示含义圈示意。
5. 日记的“今天没去面试”仍是用户报告；“以后一定失败”仍是推测，两者不能互相冒充。
6. `test/quote_insight_test.dart`、`test/cognitive_core_test.dart`、`test/quote_comparison_test.dart` 的新增回归必须通过；按 `.github/workflows/quote_insight_ci.yml` 执行完整 Flutter 测试和静态分析。

## 后续仍需真实体验验证

这是一次针对“结构和语义约束”的改进，**并未实际证明各家模型一定会提供高质量的哲学解释**；下一步应使用原典节选、隐喻、容易混淆的概念及反例，进行至少数十个真实模型响应的人工盲评。概念外延圈的逻辑形式、原文译法准确性与真实因果判断仍需专家或可独立验证的证据；模型自评不能代替核对。AI 自动生成的旧名言不会被后台自动重算，必须主动新建分析才使用新版契约。

## 第9节含义圈的原典边界（补充校勘）

原典说明五类概念圈图式：① 两圈完全重合；② 一圈包含另一圈；③ 上位圈恰好由互斥的多个下位圈充满；④ 两圈部分相交；⑤ 两个互不相交的圈同属第三个更大的圈、但并不充满它。当前双名言比较只实现第①、②、④类的双对象示意，以及互斥的二元特例；第③、⑤涉及第三个及更多概念，**不能把二元排斥图冒充完整的三元关系**。日后只有在实际已有可靠的多概念分类数据时，才应逐步扩展多圈布局。
