# 六模块证据成长 v2.7 实现说明

基线：PR #160，提交 `94e8e6b7a3b168a737117ff3931c8a5afb2b92f9`。
需求基线：用户提供的《正式产品方案 v2.7 问题空间覆盖与多目标持续生命周期闭环版》109 页。

## 改动边界与复用

只修改 evidence_growth、它的原生提醒类和该模块 CI/APK 分支条件。继续使用原有 173 个知识节点、统一 AI 配置、混合检索、行动算子、行动前风险门、不可改写的 Trial 预测、完整复盘/决策引擎、精准闹钟授权和 SQLite outbox。没有重写其他发现之旅模块。

原有 Trial 循环提升为父 GoalJourney 下的行动：Journey 保存用户目标合同、生命周期、循环位置、当前计划版本；Trial 保存实际行动与事前预测。父目标的达成只在有限目标 Goal Gate 内核验，Trial 完成与路线退出均不能直接结束父目标。

## 恢复、并发与兼容

- 旧循环按 cycle_root 迁移为同一父目标。迁移使用稳定 ID，不修改原预测、原 Trial 与旧提醒次数政策，也不把已完成 Trial 认作目标达成。旧记录首次进入目标页时核对合同。
- Journey + journal + Trial 归属映射存于 SQLite。Trial 事件与父目标推进在同一事务提交，重复创建、旧版本、新旧周期交叉写入都会回滚。
- journal 由 SQLite 触发器禁止 UPDATE；目标达成档案、稳定期档案、计划差异、重开事件追加保存。用户主动删除全部个人证据仍可执行。
- 目标旅程/组合与 Trial 分别做摘要同步。远端 CAS、离线恢复、不可改写历史校验，冲突不自动覆盖。用户比较选定当前状态后合并不可变历史，并先归档两份原快照。
- 新增 `/v2.7/problem-space/resolve`、`journeys`、`explorations`、`portfolios/.../arbitrate`、`dependencies/evaluate`、生命周期/参与者动作和 `sync`。部署的自建同步服务需要同步升级本分支；原 `/v1` 接口继续保留。
- 新行动可设置提醒最大次数，原任务缺省值仍代表原有无上限政策。后台到上限写入 NO_REALITY_FEEDBACK，收到实际反馈后清除；不将其统计为人格或能力失败。

## 验证范围与交付边界

仅运行 evidence_growth 相关静态分析、业务/UI 测试、独立 API 分析与完整 release APK 编译。新增覆盖三轮完整业务、原预测、证据达成、探索提升、保持恢复、资源冲突、依赖循环、共同意愿、拒绝对象、暂缓、计划版本、改变复发、资产迁移、API/CAS、恢复与界面绑定。问题空间测试包括正交维度成对覆盖和明确的高敏感组合。

专业领域包没有凭空新增；领域答案需要后续接入可审计资料。当前 App 没有第三方参与者登录/加入确认机制，明确返回 CAPABILITY_OR_PERMISSION_GAP，不能给第三方发任务或伪造承诺。真实 AI 提供商、通知权限、厂商省电、杀进程/重启交付还需在用户设备上确认，编译成功不等于已完成真机验收。


## 2026-09-19 运行链路复核与修正

此前的 94 项测试证明已实现的路径能运行，不能证明 109 页方案已经完整验收。这次发现并修复了以下真实断点：

| 断点 | 修正后的可观察行为 |
| --- | --- |
| 新周期清空 CHANGE，上一轮确认的动作丢失 | 保存 next_change / last_outcome，由共用 JourneyRuntime 编译下一动作；当前页显示继承的改变 |
| 新计划可能继承旧 ACT 的冻结条件 | 比较实际行动/批次的计划版本；新版重新编译，Trial 保存 plan_id、plan_version、campaign_id、goal_version；旧绑定不改写 |
| Campaign 只有编号，每个微动作强制复盘 | 一个周期内可收集 1–20 次真实反馈；样本数、截止窗口、重要事件或用户明确提前结束触发学习边界，再经过准备度、复盘、改变、目标门 |
| 已绑定输入仅作为孤立文字显示 | 首页和学习入口都可选已有目标；补充文字跨 Gate 保留，提供接回当前步骤的入口；在行动、结果或上下文确认时使用 |
| 历史学习、计划修订仅有原始 JSON | 页面展示批次事实、计划差异理由/依据、各轮学习和下一步；每个历史行动仍可单独核对原预测 |
| 阶段可以直接覆盖，子事件未实际回写父目标 | 阶段推进需要完成本轮学习并确认退出条件的现实证据；子事件通过追加记录回写父目标，不改变父目标标准或达成状态 |
| 终态可通过非 status 操作修改证据 | 终态写入必须先重开；原始达成档案保持只读 |
| 通用组合 patch 可绕过依赖检查，过期恢复仍抵消高负荷 | 组合字段白名单；新增解除依赖操作；高负荷需要未来有效恢复时段 |
| EXIT 只记日志，已关闭路线仍可安排新任务 | 手动/Trial 决策关闭当前路线；再次执行要求用户明确选择新路线 |

样本采集保留每个 Trial 自己的原预测；不同动作不能合成为同一个预测。一轮达成学习边界后才发生整体复盘，单次完成不等于计划有效，更不等于目标达成。历史批次的原始事实进入 AI 上下文，但模型结论仍须用户确认。

### 尚不能宣称全部方案完成的边界

- 当前问题空间定位仍以可纠正的本地规则为入口；真实模型服务的全场景理解能力需要使用实际配置验证。
- 计划中的自然语言时间、资源、停止与选择规则会进入行动编译及确认清单；已实现的硬约束是结构化组合预算、明确占用时段、依赖与路线/意愿门。不能声称任意自然语言规则都已被自动执行。
- 七类关系均可留存和解除；REQUIRES/BLOCKS/CONFLICTS_WITH 有直接执行约束，其余关系提供支持/替代/资源关联信息。没有把它们冒充自动求解器或父目标达成证据。
- 阶段条件、保持区间与目标达成证据目前通过用户事实确认；没有假装自动测量外部现实。周期目标复用保持检查/新周期入口，未宣称存在领域专属自动排程。
- 多人真正登录加入、可靠专业领域包、自建同步服务部署、跨设备同时离线的真机验收、厂商后台提醒与重启交付仍需要相应环境；这些不能用模拟状态冒充完成。

验证记录以本 PR 当前提交的 CI 和 APK Delivery 为准。旧提交的 94 项通过与旧 APK 不代表本次修复的验证结果。


## 2026-09 知识运行链补强

六节点共用情境知识入口：结合目标、最新输入、当前事实、结果、信念、计划与用户当下问题召回候选，支持跨模块迁移和全库浏览。缺少匹配时显示知识缺口，禁止用模块第一条充当依据。

学习页展示机制、课堂语境、案例、How-to、前提、反向信号、误用边界与来源；可让现有主模型针对单条知识讲解，并校验引用 ID 和摘录。打开卡片不再计为已学会。自我解释、具体练习、预期信号和实际反馈分别保存；记录反馈不代表已经验证掌握。

用户确认的知识应用存储原知识快照、版本、目标节点、生效轮次、自己的理解和具体用法。未开始的 ACTION 编译使用所选方法和实际动作；已创建 Trial 及已走过节点的新增用法排入下一轮，不改写原预测。复盘可追加新的、已确认的过程知识，原行动证据保持不变。节点日志区分检索候选、用户选择用法和知识缺口，复盘另记实际引用来源。旧轮知识不自动在新轮生效，需重新核对情境。

JEV 是可选的 TypeSafe 原生 typed API 匹配助手（`POST https://api.typesafe.ai/v1/systemone`, `jev-latest`），不使用 chat/completions 冒充支持。每次最多 12 条摘要，分别判断相关性与显式边界冲突；缓存相同情境、限制请求体、超时和服务异常回退本地。JEV 结果仅辅助排序；0.75/0.2 是暂定筛选阈值，未经业务标注集校准，不能自动确认适用前提或绕过风险门。密钥通过已有 Android Keystore 加密，设置不进入旅程导出或同步。点击按钮才发送当前情境，主生成模型配置不变。

覆盖边界：全库和跨模块入口支持广泛情境探索，不代表任意场景都可正确判断；词法召回可能漏掉语义候选，可全库选择补充。尚未配置真实 JEV 密钥进行在线验收，自动测试使用模拟服务。Android 安装与真实生活反馈仍需设备验收。
