# 可复现演示

## 离线闭环（不需要 AI 密钥）

1. 打开发现之旅中的「意志之镜 · 把想法变成行动」。点击例句自动填入，或输入「我想完成作品集，但资料还不齐」，点「开始我的课题」。
2. 在「事实与想要」分别添加事实「已有三份可使用的作品」、信念「我担心做不好」、未知「评审要求尚未确认」。确认分类和来源；实际发生时间不知道就留未知，系统另外保留记录时间。
3. 打开「理由与路线」。查看最多 5 条理由及证据/反例/失效条件，展开完整候选池。离线显示实际的 3 条本地候选，不显示假的在线 50 条。
4. 在一条路线中点「核实现实条件」，保留想要、身体技能、资源和安全的不同判断。可以新增自己的路线。暂停的危险手段不能靠提高评分解锁，应建立安全替代路线。
5. 在「封存本轮事前计划」填写真实触发条件、如果—那么和备用方案；预期结果与获得后感觉可不填。到「回访与原则」可查看快照哈希与原始内容。
6. 切到「现场核实」。在条件未到时先记录一项已经完成的准备。不要点击确认触发来模拟提醒送达；真正有了条件后再核实。即使确认并作了选择，也仍没有尝试或完成记录。
7. 如实记录一次尝试，再记录「遇到阻碍」或「只完成一部分」及外部因素。检查准备没有被抹掉，因果影响和满足仍为未知。也可以在没有行为时记录结果未知。
8. 在「回访与原则」记录后续体验，区分刚发生、日常体验和较长时间。选择真实证据拟一条个人原则，编辑条件、行动、例外与下一次检验。保存先为候选，点认可后才可复用。
9. 新建另一个课题，在现场原则卡点「选择已认可的原则」，明确允许来源引用并确认条件适用。查看条件/行动/例外。打开卡片不会自动记为想起或采用；必须单独报告。没有具体准备、尝试或结果时，不能标记已经应用。
10. 在来源课题补充反例并修订原则，回到目标课题确认旧应用失效、旧快照的版本引用没有被重写。撤回源证据后，相关分析清空，原则失效；删除课题后其引用也停止使用。
11. 开始下一轮，确认相同课题 ID 保持、多轮经历仍在。首页「进阶工具」可继续旧版练习、Deep Why、探针、Real-Me、实验与知识库。课题库中的旧目标打开后沿用原 ID，可按需关联旧经历。

## 可选在线分析

在宿主设置中配置自己的 AI Provider。进入课题点「授权 AI 梳理」，只勾选本次可以发送的记录，再确认；其他资料与课题库不发送。检查生成回执、实际候选数、正反关系和未知项。中途撤回授权后，后续请求与未返回结果不再使用。未配置或失败时确认显示本地降级。

如果需要 Decisions 评分，按 [代理说明](../../server/will_mirror_decisions/README.md) 部署并配置 HTTPS 服务地址与独立服务令牌。请勿在移动端此字段填写 OpenAI 密钥。检查 0–4 量规、置信度与证据档位分离、拒绝/缺失答案仍为未评分。

## 真机待核验清单

- 自选未来时间安排提醒；锁屏只出现通用文字。前台、后台、冷启动点击均回到对应课题与计划，且触发/行动仍未知。
- Android 重启、系统省电、关闭通知权限后的行为；不保证精确投递时间。
- 暂停计划、记录结果、撤回证据、删除课题或删除整个 Vault 后，不再使用失效提醒。
- 手动打开文本卡、拒绝语音、停止朗读、TalkBack、大字体、返回再打开均能继续。
- 使用 Android Keystore 真正加密存储并执行整库密钥销毁；单元测试使用替身密码器验证存储边界，不代替硬件验证。
