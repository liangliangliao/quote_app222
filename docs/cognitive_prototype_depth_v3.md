# 概念关系、根据图与原型验收

本轮修正历史收录集合与概念外延混淆的问题，并按《作为意志和表象的世界》第一卷第九节的五种图式绘制关系。依据 [第九节公开文本](https://www.gutenberg.org/files/38427/38427-h/38427-h.html)。

| 图式 | 绘制要求 | 界面验收样例 |
|---|---|---|
| ① 外延重合 | 一个圈内同时标出两个概念 | [等边与等角三角形](cognition-v3/five-equal.png) |
| ② 完全包含 | 保留包含方向和外层独有范围 | [马与动物](cognition-v3/five-subset.png) |
| ③ 互斥且穷尽上位范围 | 支持两个或更多子类，每类有判准和实例 | [按角划分三角形](cognition-v3/five-partition.png) |
| ④ 部分相交 | 交集和两个独有区域均可查看 | [红色物体与花](cognition-v3/five-overlap.png) |
| ⑤ 同属上位范围且未穷尽 | 画出并命名共同上位圈，说明其余成员 | [水、土与物质种类](cognition-v3/five-siblings.png) |

## 分析流程

开启「设置 → 叔本华认知风格」及「显示概念关系图」。

- 阅读一条名言时，点「分析概念关系并绘图」，由全局文字 AI 分析整句中的概念、成员判准、量词、否定和条件，再决定图式。
- 比较两条名言时，新请求同次返回 A 句内、B 句内和跨句概念关系。三个范围分别有来源摘录和判断理由，能逐项切换。[比较入口验收](cognition-v3/semantic-pair-A.png)。
- 在历史关系图中选择主题概念，再点分析按钮。原记录标签用于选择材料和打开收录。概念外延关系来自对所选材料的语义分析。
- 「概念星图」使用同一份语义分析，连线标明对应的五种图式编号，可选择关系查看完整含义圈。
- 概念详情、日记注释和电影概念页使用同一个关系分析入口。

不足以判断时，模型应说明具体缺口并返回待定关系。界面保留已有的句内分析，并显示跨句关系的缺口。首次分析使用用户配置的文字 AI，已有结果可从本地读取。主动重新判断会使用当前配置的模型。旧版单词圆、离线阅读模板和按收录数量推导的包含图已从上述入口撤下。

## 根据律图示

同一分析结构可以返回认识根据、因果条件、时间先后、空间位置和动机关系。每一图分别标注类型、方向、原文出处以及原句主张或暂定解释。

认识根据从根据指向判断，因果从可能原因指向变化，时间表示先后，空间按原文给出左右、上下或内外关系。模型不能把引文中的条件主张直接标为已经证实的因果。

## 验证边界

截图取自 Flutter 界面测试，使用明确标记的验收样例及模拟模型响应。自动化检查五种图式、三分穷尽、原文对应、A/B/跨句覆盖、根据类型、缓存更新失败保留、真实入口和放大文字。实际供应商输出和 Android 真机操作仍需验收。

解析器检查来源、字段与图式的一致性，不能据此保证模型的概念判断在哲学上必然正确。界面区分按原句主张、依定义和 AI 暂定解释，支持查看判准、根据及重新判断。
