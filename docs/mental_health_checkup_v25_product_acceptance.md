# 心理健康体检 V2.5 产品验收边界

本文用于区分“已经落地的工程能力”和“仍需真实人员、供应商账号、真机或上架流程完成的验收”，避免把候选内容、自动化测试或 CI 安装包误称为最终产品签发。

## 已实现的工程能力

| 能力 | 实现状态 | 关键边界 |
|---|---|---|
| 发现之旅入口与完整体检流程 | 已实现 | 本地完成安全分流、问卷、报告、课程行动、执行记录、复验与恢复维持 |
| 课程权威本地知识库 | 已实现 | 运行时使用 2,253 个课程位置、345 项内置指标及 1,380 条内置证据关系；不依赖网络 |
| 候选指标发现 | 已实现 | 支持本地治理骨架和 AI 候选；候选 ID 由本机生成，AI 不得指定或发布 |
| 候选指标治理 | 已实现 | 草稿、候选、认知访谈、试测、正式、停用；含版本、质量门、角色隔离和审计记录 |
| 候选题目生成 | 已实现 | 按指标类型生成规定的 A1—A9 适用题型，保留指标 ID、课程证据 ID、量尺和安全边界 |
| 候选任务生成 | 已实现 | 支持 B0—B4，保留微量版本、反证、停止规则与迁移/复发要求 |
| 批量生成 | 已实现 | 按全部课程或指定 Lecture 建立持久化任务队列，支持 5/10/25 项分块继续、失败重试和取消 |
| AI 本地 RAG | 已实现 | 默认只发送本地检索后的课程证据，不发送用户回答、报告、行动记录、安装标识或支持号码 |
| 供应商知识文件复用 | 已实现 | OpenAI、Eden AI 可首次上传课程专用 JSONL 并保存文件 ID；后续候选生成直接复用 |
| 供应商资源生命周期 | 已实现 | 按供应商账号指纹、课程版本和 SHA-256 隔离；课程变化自动失效；支持停用与解除关联 |
| 无网/供应商异常回退 | 已实现 | 体检主流程始终本地可用；AI 或文件输入失败时生成本地草稿，不把失败内容发布为正式题库 |
| 数据清除与隐私提示 | 已实现 | 可清除本模块本地数据和文件 ID 关联；远端文件是否成功删除会如实提示 |
| APK CI 产物 | 已配置 | PR 工作流在测试、严格分析和 release 构建通过后上传 APK、SHA-256 和构建信息 |

## AI 知识库运行方式

1. 默认方式是“本地权威知识库 + 每次本地检索 + 发送最小课程摘录”。
2. 用户可选择把仅含课程内容的 JSONL 首次上传到支持的 AI 供应商。
3. App 只保存供应商文件 ID、非密钥账号指纹、课程版本和内容哈希；API 密钥仍由原有全局 AI 设置管理。
4. 后续候选指标、题目和任务请求会复用匹配的文件 ID，同时携带本地证据 ID用于校验和审计。
5. 若供应商、账号、课程哈希不匹配，或资源被停用/失效，系统自动改用本地 RAG。
6. 课程知识文件明确排除用户健康数据；任何用户体检数据都不会混入可复用的供应商知识文件。

## 不能由代码假装完成的事项

以下项目在真实证据产生前必须保持“待验收”，不能仅凭页面勾选、AI 分数、单元测试或 CI 成功宣称完成：

- 课程专家逐条确认新增指标和内容的课程忠实度；
- 独立审核人完成构念、去重、量尺、证据和安全边界复核；
- 目标用户认知访谈；
- 小样本试测及缺失率、区分度、稳定性和安全反馈分析；
- 人工签发正式指标、题目和任务；
- 使用真实 OpenAI/Eden AI 账号验证上传、文件输入、计费、保存期限和远端删除；
- Android 真机上的升级迁移、低内存、离线、进程终止恢复、无障碍和机型兼容验收；
- 正式签名、隐私合规、应用商店审查和发布。

因此，CI 全绿代表“当前提交在自动化范围内可测试、可分析、可构建”，不等同于完成上述人工、供应商、真机或上架签发。
