# 足下一致行动 · 认知失调 V4 完整产品闭环升级说明

本次 V4 重点不是继续堆叠独立页面，而是把 V3 中剩余的系统级闭环补齐，使“足下一致行动”从独立模块进一步嵌入 Todo 目标价值系统、问题树、行动证据与周期报告。

## 1. Todo / 问题树双向回写

- 在行动陪伴页新增“Todo / 问题树双向回写”选项卡。
- 当来源为 `todo_goal_step` 时，保存一致行动证据后会：
  - 写入 `goal_effort_entries` 足下努力账本；
  - 写入 `goal_reflections` 复盘记录；
  - 可选择是否同步标记今日行动完成。
- 当来源为 `todo_problem_node` 时，保存一致行动证据后会：
  - 写入问题树节点努力记录；
  - 同步更新问题树节点状态为进行中；
  - 可选择是否标记节点完成。

## 2. 问题树节点接入一致行动

- 在问题树节点卡片中新增“一致行动”按钮。
- 可将问题树节点的标题、可执行动作、验收标准、证据需求传入认知失调雷达。
- 行动完成后能够反向回写节点努力与节点状态。

## 3. session 继续执行数据一致性修复

- 从“最近 AI 方案链路”继续执行历史 session 时，会同步恢复：
  - 用户目标；
  - 用户上下文；
  - 用户价值；
  - 当前行动计划。
- 避免历史 session 继续执行时，证据记录到错误目标或空目标上。

## 4. 报告 → 下一步行动闭环

- 历史价值一致性报告卡片新增“根据这份报告生成下一步行动”。
- 可将报告内容重新作为上下文，生成新的 1 美元行动。
- 实现：行动证据 → 周期报告 → 下一步行动 → 再执行。

## 5. 证据趋势与系统融合看板

- 身份证据账本新增“最近趋势与系统融合”卡片：
  - 最近 7 天证据数量趋势；
  - 价值靠近 Top3；
  - 来源转化 Top3；
  - 展示独立模块、Todo 今日行动、问题树节点、报告续行动等来源的转化。

## 6. 数据链路增强

- `cc_evidence_records` 保存后返回 evidenceId，便于回写 Todo 复盘与问题树记录。
- 新增 `TodoGoalDao.getProblemNode()`，支持通过 nodeId 获取问题树节点并回写努力记录。
