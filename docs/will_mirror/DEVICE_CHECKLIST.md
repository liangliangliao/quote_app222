# Android 与辅助功能验收

状态：云端完成 ARM64 release APK 编译和 Widget/SQLite/HTTP 合约测试；**下列真机项目尚未执行**。本环境没有已连接设备或 Android 系统镜像。

至少使用 Android 13+（运行时通知权限）和 Android 12 或以下设备各一台，另选一个有后台省电限制的厂商系统。记录机型、系统、App 提交、结果和截图；未知不可填通过。

| 项目 | 操作 | 预期 |
|---|---|---|
| 独立入口 | 发现之旅打开模块、返回、重新进入 | 一个入口；课题/逐渐认识的我/设置；其他发现入口仍正常 |
| 既有数据 | 升级前备份，再覆盖安装 | 旧 V4/V5 文件与原 Keystore alias 不删除；新库 `will_mirror_rebuilt_v28.sqlite` 独立；不自动导入旧推论 |
| 本机密钥 | 新建课题，杀进程再打开 | 原生 Keystore AES-GCM 可解密；篡改密文应失败，不能换空库 |
| 卸载边界 | 仅测试设备操作 | 卸载会丢设备密钥；“设备绑定加密档案”不承诺跨设备恢复；先用用户主动导出 JSON |
| 离线 | 关闭网络 | 查看已有资料、记录真实反馈、暂停/删除仍可用；不生成假 AI 结论 |
| 通知拒绝 | 第一次拒绝通知权限，再封存 | 预案保留，记录 denied，不显示已投递/已注意 |
| 通知允许 | 用户主动设置未来时间 | 锁屏仅中性文案；无私人课题、健康、动机正文 |
| 热启动回链 | App 前台时点系统通知 | 原 Case、原计划/触发/场景版本、现场步骤；仅登记打开，不自动登记条件已发生 |
| 冷启动回链 | 结束 App 后点通知 | 导航准备好后进入同一目标；不丢 payload，不重复创建 Case |
| 旧通知 | 更换计划、换路线或新一轮后点旧通知 | 拒绝旧版本，不重新激活旧预演；历史仍可回看 |
| 撤回 | 封存后撤回原事实/跨 Case 授权 | 派生图边、场景、原则、历史副本删节；OS 旧任务取消 |
| 删除 | 有提醒时删除 Case/全部资料 | 旧通知不能读原文，入口不残留缓存；其他模块资料不受影响 |
| 重启 | 设置提醒，重启后打开或到时 | BootReceiver 恢复可恢复安排；不得把恢复视为投递或真实触发 |
| 省电/时区 | 省电模式、时区变化、延迟交付 | 调度延迟不算用户失败；现场仍需核实；重入时核对 pending 任务 |
| 安全变化 | 现场记录安全条件变化 | 旧预案/预演停用，提醒取消；保护性走法/暂停可用 |
| TTS | 显式开始预演，暂停/跳过/切后台/撤回 | 默认不自动播音；随操作停止；选用的 Android 语音引擎策略另需核实 |
| 减少动态 | 设置关闭动画，或启用系统减少动态 | 动机之潮静态显示；业务可完成，不靠动效表达唯一信息 |
| 大字体 | 390×844 与更窄设备，字体 1.6–2 倍 | 正文、按钮可读可滚动；无横向裁切重要操作 |
| TalkBack | 从输入到真实反馈及原则详情 | 控件标签可读、焦点有序、时间轴具有文本等价内容 |
| 数据导出 | 主动导出 JSON/设备绑定加密档案 | 不含服务 API key/网关 token；取消文件选择不报成功 |

本地通知采用 Android 非精确调度，系统省电可能延迟。界面保留手动进入现场记录的路径。原生能力测试不能由 TestCipher 或 MockReminders 代替。
