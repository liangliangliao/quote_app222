## 结构约束

- 发现之旅只有一个公开模块入口；模块内导航为「课题／逐渐认识的我／设置」。
- 一句话建档，同一个 Case 的工作台依次展开理解、动机、认知转换、路线、准备、现场、揭晓；已完成步骤可折叠回看。复杂数据在详情中展开。
- 领域层无 Flutter/宿主依赖；应用层处理命令、异步阶段和撤回；SQLite 保存加密、带版本的聚合与索引；宿主适配仅连接 AI 配置、导航、通知和 Android 密钥库。
- 每条记录区分来源、T0/T1/T2/T3、发生/得知/记录时间、支持/反证/依赖、修订。未知不能改成未行动、已失败或已验证。
- 事前封存内容不可被事后分析覆盖。隐私删除优先于保留原文，历史显示删节而非伪造完整哈希验证。
- 所有推论可否认、修订和撤回；传递依赖失效覆盖图边、路线、预演、榜单、原则、跨课题引用和提醒。

## 必须在工作台实际可用的功能

1. S1 事实／信念／未知分离；S2 个体欲求和反证；不强制问卷。
2. S3 分批生成并语义去重 50–70 动机；不足如实说明。直观／抽象与方向、时域独立。Top5 预筛保留重要反方、风险、长远理由，固定四维量规、缺项未知、可调权重和来源。
3. 旧认识到可检验新认识；选择少数相关算子，保留旧认识正确的可能、竞争解释、最小实验和前后动机关系差异。
4. 动态路线及欲求×时间矩阵。欲求适配、难度、任务能力、外部可行性、认识条件、安全门槛分别呈现。支持变体、真实资源竞争、暂缓与放弃、未来累计后果独立。
5. 真正可执行的准备、干预及实施证据；事实／未来／障碍／应对／现场短提示的可选预演，用户确认和反馈，允许全程静音及减少动态。
6. 条件性预案、预测封存、提醒与现实触发分离。现场双边理由及风险重审，改道／暂停／拒绝合法；决意、尝试、行动、外部结果分别记录。
7. 事前／现场／事后对照、首次偏差、竞争性障碍和可改变性、补救与下一次实验、实际取得和持续体验分离。
8. 同 Case 多轮真实历程；之字形实际道路实线／未走方向虚线。生活领域和可能联系可独立、未知、反驳，不计算人格总分。
9. 原则最多三个候选、默认一条；支持反证、适用条件、If–Then、用户认可、真实调用与运用、反证修订。优势按具体任务、第三方自主及法律义务有边界。

## 验证与诚实边界

`acceptance.json` 收录 T1–T366 原文，逐项补充代码、可复现自动测试或真人/设备验证需求。
自动测试不能证明真实模型推理质量、心理效果或 Android 所有机型通知可靠性。线上 Decisions 服务要以官方 API 契约为据、实际错误降级；禁造分数或已调用声明。
开发只复用用户任务说明已授权的宿主 Provider，不新增或提交 API key；每次远程推理仍需应用内最小证据授权。默认本地加密、无私密日志。
