# 叔本华认识论审计与 Token 改进 v9

基于 PR #207 的 `9e7f99b7da6e338a7fa2358b502fd266ec388ded`，对应 2026-11-03 审计路线图的全部 P0、P1、P2。五个主题共用预算与语义协议，集中在一个修复 PR 交付，避免安装不同批次时协议不一致。本文件描述 v9；v8 文档中的隐藏 10000 限制、自动一次质量修复、日期倒序已被以下行为替代。

## 1. 实际额度、实际消费和响应恢复

全局最大输出保留用户填写的 90000，含义为上限；不再静默改成 64000，也不覆盖所有任务的自身预算。文字、消息和附件经统一调用时均采用同一解析器。实际额度为任务预算、已设置全局上限、已知模型限制的最小值；当前无法可靠发现服务端模型能力时明确显示未知，不猜测模型上限。

概念图与比较默认 10000，分支展开 4000，局部修复及主动辅助核验各 2000；其他业务沿用自身声明的预算。任务额度可独立调整；其他已记录的文字任务也可以在请求记录中展开后调整，分类批次保留成本策略保护。例如全局 90000 下将概念图改为 24000 时，实际请求会发送 24000。分类另受既有批次成本策略保护，不叠加传输重试。

设置 → 全局 AI 参数 →「查看任务额度与实际用量」可查看各任务预算及本机最近 100 次统一请求。概念图及比较入口也显示生效额度。记录每个实际发送及其操作标识，展示输入、输出、缓存命中和输出中包含的推理数；累计流式 usage 只取最终/最大计数，不重复相加。没有返回的计数显示未知，不计作零；这些数量不是金额估算，也不是付费前预扣额。

相同系统方法只注入一次；比较不再要求模型重复序列化 reading_a、reading_b 与 semantic_map。语义图可使用 evidence 引用表，同一摘录只生成一次，节点、边和判断引用短 ID，再由客户端展开并核对原文。辅助核验一次只处理用户选中的一个命题。

保持流式接收、超时、Azure 端点兼容以及普通 JSON 网关兼容。输出截断明确报告实际额度及结束原因；不会自动抬高额度、续写或重发整图。结构校验只在本地执行；修复由用户主动触发，提交问题片段与已有节点身份并返回增量。模型声称 resolved 不足以清除错误，须有同身份、已通过本地解析的替换项。失败与残缺结果不覆盖成功缓存。可以停止接收；已发送请求仍可能产生费用，没有返回的用量保持未知。

## 2. P0：命题、根据、五种圈图和材料深度

- P0-01：协议 v3 保留命题的主词、谓词、量词、否定、条件、模态、引用及结论。本地规则只能判定一部分转述一致性与明确矛盾，不能作为通用语义证明器。逐字一致只说明忠实转述；引文存在不能验证另一句话。弱量词被强化、否定反转等给出具体缺口，不能以图形确认。
- P0-02：删除四层、两个经验、五个连通概念、四条关系及 24 字定义等质量门槛。深度与圈数只用于描述，不用作质量分数。简单事实保留事件和条件；形式定义允许直接连接形式构造；长论证保留必要的中介概念、前提与直观依据。不能用“概念名＋具体表现”作为经验叶。
- P0-03：阅读、比较、认知日记、电影及名言生成共用五种圈图协议和验证器。重合、包含、划分、交叉、同上位范围的并列分别要求相应的论域、判准、区域成员和上位范围。缺区域、区域冲突、重复划分身份均不能当作有效图。v3 从节点身份引用同一概念定义，防止换判准；相反方向的真包含环和不相容的重合、交叉、互斥断言会被标出，不能用两张局部图掩盖矛盾。收录标签、共现与词义相近不建立外延或因果。局部几何布局通过不表示哲学判断或成员事实通过。
- 模拟例仅作教学说明，形式构造与生活事件分开；预置教学图不再替代所选原文的分析，而是单独的可选入口。无可靠圈图时推荐定义、概念树、判断或根据等合适视图；单独概念预览不表示排斥、包含或重合。
- P0-04：设置 → 阅读与认知风格 →「哲学材料真实模型验收（手动）」提供六组材料：正方形/长方形、旅行/健康/幸福、尼采树的隐喻、判断目的、时间空间与四类根据、日记事实/解释/预测。每组点击一次才发起一次生成，默认不自动核验、重试或运行全套。保存原始输入输出、配置、提示词、版本、用量、错误类别及人工复核。六项人工维度未全部复核时不算通过，无综合认知评分。尼采测试文案明确标为教学译写，不能充当已核定版本的引文。

《作为意志和表象的世界》第一篇关于概念依赖直观内容、含义圈和判断力的讨论是产品方法参考；不同版本的章节编号与译文须结合原段核对。本实现不能用章节号、引文命中或 AI 自评替代哲学与出处审校。

## 3. P1：目的、四类根据、时间与来源

- 比较按对象、目的、相关共同点、决定性差异、条件判断和改判触发条件组织。切换目的/条件后的结果保存独立修订快照，展示旧差异、新差异、证据、修订理由；恢复旧判断会追加记录，保留中间历史。
- 存在根据的时间/空间、生成根据的因果条件、认识根据及行动动机分别标注。时间戳、地点只是记录线索；发生变化的原因不同于相信这个原因的证据；没有明示的动机保持未知。
- 时间线跨日期及日内都从早到晚，排序先于数据库分页；物理洗牌不改变时间顺序。重复名言以记录实例而不是内容散列定位焦点，相同时间稳定排序，未知时间单列。此刻是所选记录的参照点，可以定位已加载的最新记录，不冒充设备现在时间。
- 经验概念可通过必要的概念中介返回直观内容；形式构造无需编造人物、地点或动作。电影梗概、AI 解释、用户报告、引文和教学文本分别标注。

## 4. P2：开关、修订与缓存兼容

基本的忠实性、来源与推理约束始终保留。深度认识论表达受开关控制；关闭时普通名言生成、电影解读和比较不强制输出概念树或圈图。显式选择语义分析与验收时才使用完整方法。

日记、发现之旅、想记、知行等沿用所选记录的本地修订链，不自动检索其他记录；修订可记录反对材料或替代解释，保留原判断、支持材料、改判理由及回退历史。人工分类和原文不由分析失败或版本升级改写。

语义协议 v3、生成提示词 v4、比较提示词 v7、认知提示词 v5及共享方法 v5分别参与治理。旧版缓存继续可读，标明旧版与尚未核验；解析/合并不会把旧数据自动升级为新版本已验证。升级、浏览、切换视图不发起付费重算。

## 5. 验收边界

自动测试使用本地 HTTP 服务、离线样例、SQLite 与真实 Flutter 页面。应覆盖预算、实际参数、usage 去重、输出截断、取消、无自动修复、共享圈图协议、短定义、修订恢复、时间顺序、旧缓存、开关与人工数据保护。CI 另运行既有业务与关闭开关回归并生成 APK、来源信息及校验和。

完整工作流范围的 274 项本地回归与静态检查通过；随后增加 Foundry 参数兼容、简单事实及预览复核，最终结果以 PR 对应提交的 CI 为准。未使用用户手机凭据，也未调用真实付费模型。本地测试通过只能说明结构与功能通过；真实提供方响应质量、中文哲学解释及六组真实输出仍须在 APP 中手动运行并人工复核，不声称已完成哲学质量验证或保证外部网络永不中断。
