# 知行树：文档分析与产品落地说明

本模块依据以下两份正式资料实现：

- 《知行树_智能行动成长系统_正式产品化方案_V1.0》
- 《知行合一智能行动成长系统_第一二三批累计知识库_V1.2》
- `docs/zhixing_tree_v3_productization.md`（V3.0 重大产品化改造与15项验收矩阵）

实现目标不是“思想名言推荐”，而是一个可离线运行、可审计、可恢复的闭环：

> 一个真实目标/问题 → 点选当前卡点 → 系统自动匹配思想并给出唯一主动作 → 极简反馈 → 自动复盘 → 继续、换思想或融合 → 下一轮行动

产品前台不做疾病诊断，也不在行动前进行问卷调查。COM-B、容量与风险规则仅作为本地后台的行动适配和必要安全保护；普通行动的前台输入压缩为“想推进什么、可选下一小步、可选价值理由、投入时长”。

## 匹配公式

实现严格采用产品文档给出的权重：

```text
Fit =
  0.30 × 障碍匹配
+ 0.18 × 阶段匹配
+ 0.14 × 方法相容
+ 0.12 × 价值/意义相容
+ 0.10 × 证据直接性
+ 0.08 × 容量相容
+ 0.08 × 历史反应
- 冲突惩罚
- 安全惩罚
```

历史反应最多只占 8%。用户关闭个性化后，该项恢复中性值；任何历史偏好都不能越过安全、容量、第三方或专业判断门槛。

## 证据包

知识清单包含 22 部作品/体系和 22 个机制级镜头。每个镜头记录：

- 核心问题与机制；
- 最佳适用和不适用场景；
- 前提、禁忌与证据直接性；
- 适用障碍、阶段、难度和方法；
- 行动模板、理论张力与知识库定位键；
- 审阅状态。

`zhixing_thinker_catalog.dart` 在证据清单之上增加面向用户的作者/体系整合层。22个作品级镜头不再被错误展示成22套彼此独立的思想，而是完整归入17套思想体系：

- Nietzsche统一整合《查拉图斯特拉如是说》《快乐的科学》《善恶的彼岸》《道德谱系》；
- Dewey统一整合《我们怎样思维》《人性与行为》；
- Bandura统一整合《社会学习理论》《自我效能》；
- 其余单一来源继续保留独立思想家或理论体系身份。

每套体系明确记录核心价值、完整核心思想、怎样理解“知”和“行”、知行分裂原因、转化路径、行动如何回写认识、与王阳明的关系、前一层的不足、本次质变、融合结果、著作分工、七环位置、适用情境、行动方式和真实张力。

17套体系不是并列菜单，而是一条以王阳明为主干的演化路线：

1. 立根：王阳明确立真知必须进入行动的总纲；
2. 心理落地：James、Beck、Ellis和老子补足注意、认知检验、挫折耐受与非强迫行动；
3. 主体升华：ACT、SDT、Nietzsche和Frankl补足接纳、自主、价值创造、意义与责任；
4. 行动实现：Dewey、Gollwitzer、Bandura、Oettingen和行为激活补足探究、启动、学习、障碍与反回避；
5. 系统整合：Maslow、哈佛积极心理学课程和COM-B/BCW补足容量、日常转化与统一行为工程。

启动与测试会校验：17套体系顺序连续且以王阳明开始；22个已审阅镜头全部且只被归入一个体系；所有承接关系只指向前序体系；全部关联ID有效；完整知行字段不得为空。

运行时会对知识正文计算 SHA-256，并校验清单声明的来源数量、唯一镜头ID、来源引用以及所有证据定位键。任何一项失败都会阻止知识包进入产品流程。

## 页面结构

1. **现在做**：合并原“今日”和“立即行动”。常显唯一动作、完成标准、反馈入口；无活动动作时只需目标、卡点和体验方式。
2. **思想工具**：当前选用思想常显；完整17套体系、5层演化、关系、证据和原著检索按需展开；支持最多3套自主融合。
3. **成长**：合并挑战花园和知行树，以二级标签区分；奖励、学习和能力保持分账。
4. **导师**：远端书库、AI派生知识、Agent提醒与报告记录。
5. **更多**：知识完整性、提示词、个性化/游戏化、扩展候选、导出和删除。

全局悬浮“问助手”在五页均可用；应用栏帮助入口打开完整流程图、案例和逐功能说明。

行动复盘只保留两个必答项：现实完成状态、难度感觉。未完成原因、关键发现、下一次最小动作和手动思想选择均为可选；默认由报告引擎决定继续、换思想或融合，所选方案会立即保存并可直接进入下一轮行动。
