# 知行树：文档分析与产品落地说明

本模块依据以下两份正式资料实现：

- 《知行树_智能行动成长系统_正式产品化方案_V1.0》
- 《知行合一智能行动成长系统_第一二三批累计知识库_V1.2》

实现目标不是“思想名言推荐”，而是一个可离线运行、可审计、可恢复的闭环：

> 具体情境 → 安全/容量门槛 → COM-B竞争假设 → 思想镜头匹配 → 单一行动处方 → 现实证据 → 复盘更新 → 能力与成长树

## 正式范围映射

| 产品要求 | 代码落点 | 关键约束 |
|---|---|---|
| 无登录、本地优先、无AI可完成 | `zhixing_dao.dart`、`zhixing_engines.dart` | 核心流程不依赖网络或模型 |
| 22部作品与证据定位 | `assets/zhixing_tree/*`、`zhixing_knowledge_repository.dart` | 启动时校验SHA-256、来源数、镜头ID与定位键 |
| R0–R4安全门 | `ZxSafetyGate` | R3/R4阻断普通行动；R2强制二次确认 |
| 容量、第三方、可逆性和专业判断门槛 | `ZxSafetyGate`、处方页安全表单 | 先检查能否行动，再评估动机 |
| COM-B竞争诊断 | `ZxBehaviourDiagnoser` | 保留最多3个竞争假设、支持证据与反证 |
| 思想镜头匹配 | `ZxThinkerMatcher` | 机制级镜头而非思想家人格标签 |
| 低匹配与用户纠错 | `ZxThinkerMatcher`、处方/问知页面 | 最高分 `<0.55` 或前两名差 `<0.08` 且方向不同即提示；用户可否定镜头 |
| 一个主动作、三档负荷 | `ZxActionGenerator` | 主动作唯一，另提供降级与条件充足后的挑战 |
| S0–S5、L0–L4 | 领域模型、诊断与挑战花园 | 安全/容量限制可覆盖所选难度 |
| 10维×5级挑战 | `ZxChallengeFactory` | 共50项，L4固定R2 |
| 完成与学习分开 | `ZxReviewInput`、`ZxRewardEngine` | 未完成也可获得真实学习奖励，不伪装成完成 |
| 金币、XP和能力分离 | `ZxRewardEngine`、`ZxTreeEngine` | 金币只能兑换水分/阳光/养分，不能买XP或晋级 |
| 奖励防刷 | 奖励双账本、`ZxRewardEngine` | 同动作新颖度递减至0.7、难度日限次、每日最多60金币 |
| 可恢复成长树 | `ZxTreeEngine`、`ZhixingTreePainter` | 生命力使用几何平均；枯萎/休眠可恢复；无连续签到惩罚 |
| 知识搜索、证据与镜头对照 | “问知”页 | 可按来源筛选、比较两个镜头、查看适用边界 |
| 开放扩展管线 | `zhixing_candidates`、证据与隐私页 | 候选/隔离/拒绝/人工核查；未发布进新版知识包前不参与核心流程 |
| 可选AI与严格边界 | `zhixing_ai_service.dart` | 只优化表达或整理候选；不能改变风险、诊断、定位键、难度或奖励 |
| 提示词治理 | `zhixing_prompt_config.dart` | 本地可查看、编辑和恢复默认 |
| 关闭游戏化、重置个性化 | 证据与隐私页 | 不影响行动、知识与安全 |
| 导出与删除 | `ZxDao.exportSnapshot/deleteAllUserData` | 导出完整JSON；删除用户数据但保留只读知识包 |
| 发现之旅集成 | `lib/pages/discover_page.dart` | 独立入口进入完整六页产品 |

## 匹配公式

实现严格采用产品文档给出的权重：

```text
Fit =
  0.30 × 障碍匹配
+ 0.18 × 阶段匹配
+ 0.14 × 方法相容
+ 0.12 × 价值/意义相容
+ 0.10 × 证据直接性
+ 0.08 × 容量相容
+ 0.08 × 历史反应
- 冲突惩罚
- 安全惩罚
```

历史反应最多只占 8%。用户关闭个性化后，该项恢复中性值；任何历史偏好都不能越过安全、容量、第三方或专业判断门槛。

## 证据包

知识清单包含 22 部作品/体系和 22 个机制级镜头。每个镜头记录：

- 核心问题与机制；
- 最佳适用和不适用场景；
- 前提、禁忌与证据直接性；
- 适用障碍、阶段、难度和方法；
- 行动模板、理论张力与知识库定位键；
- 审阅状态。

运行时会对知识正文计算 SHA-256，并校验清单声明的来源数量、唯一镜头ID、来源引用以及所有证据定位键。任何一项失败都会阻止知识包进入产品流程。

## 本地数据与审计

主要表：

- `zhixing_goals`、`zhixing_sessions`、`zhixing_actions`
- `zhixing_reviews`
- `zhixing_reward_ledger`、`zhixing_xp_ledger`
- `zhixing_tree_state`、`zhixing_tree_events`
- `zhixing_lens_feedback`
- `zhixing_candidates`
- `zhixing_knowledge_items`、`zhixing_knowledge_fts`

复盘、金币账本、XP账本、行动状态和成长树投影在同一个数据库事务中提交。账本采用追加写入，树状态是可供界面快速读取的投影。

## 页面结构

1. **今日**：当前唯一主动作、成长树摘要、能力XP与复盘入口。
2. **行动处方**：情境输入、安全/容量门槛、COM-B竞争假设、思想匹配、三档负荷、证据和停止条件。
3. **问知**：全文搜索、来源过滤、证据详情、镜头对照、帮助度反馈。
4. **挑战花园**：10个维度、L0–L4共50项挑战。
5. **知行树**：生命力、资源平衡、成长阶段、能力维度、资源兑换与奖励账本。
6. **证据与隐私**：知识包完整性、AI透明度、提示词、个性化/游戏化、扩展候选、导出和删除。

## 验证

`test/zhixing_tree/zhixing_engines_test.dart` 覆盖：

- 22来源/22镜头与SHA-256完整性；
- R3/R4阻断、低容量限级；
- 机会障碍优先于泛化动机判断；
- 文档规定的匹配权重与直接镜头选择；
- 处方结构、停止条件、证明和证据定位；
- 完成/学习分账、每日上限、重复递减；
- 成长树几何生命力、金币与XP隔离、休眠恢复；
- 10维×5级挑战及L4/R2约束。
