# 概念关系、认识根据与本地分析版本 v13

本次处理用户“下腹（下半身）之存在……”及历史关系图的反馈，并移除页面上的 AI 用量与输出额度信息。延续 v12 的应用端不发送可选输出上限策略；早期文档中的额度编辑和旧缓存策略属于历史版本。

## 实际行为

- 阅读页共用一份分析和一个操作区。直观、概念关系、含义圈、类属树与判断切换不会卸载分析、重新生成或增加生成按钮。“重试并深入分析”可填写不满意之处及本次理解目的，把旧分析和校验问题作为待批评材料交给 AI，保留旧版本。
- 类属、组成部分、概念中介、实例、直观内容追溯及语义限制分别标注。身体部位不能作为“身体状况”的下位；个别需要与行动不能直接证明普遍心理规律。主图连接概念与具体经验，类属树保留为明确的独立视图。经验节点必须有可辨认的内容及来源，不能使用“某概念的具体表现”占位。
- 认识根据显示一组前提共同支持有条件的判断。前提之间不画先后或因果箭头；可点击回到相应个别经验。引文定位、教学案例、原句主张、分析性定义与解释保持区别。
- 新生成协议 `grounded_graph_v1` 以 ID 引用同一份概念定义和摘录；客户端转换到兼容的内部 v6 结构。原有定义一致性、来源、论域、区域及新增限定校验保留。只允许恢复引号、标点及空白的排版差异，不能模糊改写词语、否定或量词。展开时新节点、旧节点及认识根据中的经验 ID 一起重写与合并。
- 含义圈画出真实的包含、重合、相交、同属上位范围或划分区域。只有已列判断及其逻辑后果足以确定可见圈之间的相对关系时才合画；尚未比较的两圈不会凭排版补成互斥或相交。其余已知关系使用真正的局部圈图，复用原定义。合图不能满足几何约束时也保留这些局部图。
- 完整结果、部分结果、失败时收到的原始内容都存入本地数据库。失败不会覆盖上一个可展示版本；可查看并恢复旧版本。数据库暂时写入失败时保留当前图，提供仅重试本地保存的操作，不再调用模型。
- 历史关系图默认展示本地保存的概念含义圈，按原材料和目的保留独立分析，不把同名异义跨图合并。可明确选择最多六条名言建立含义关系；浏览、换分类、恢复版本均不会调用 AI。旧阅读缓存按准确材料键分批导入、重复内容只整理一次；列表读取当前版本，不解析全部失败与历史原文。
- “分类索引”作为另一个导航视图保留，连线仅表示类别归属。共同收录或主题相近不画成外延关系；分类的批量、本地优先、缓存、请求次数与最多三次失败重试机制保留。
- 阅读、比较、设置、哲学验收、分类及其他相关页面不再显示 AI Token 用量、额度、上限或“无上限”提示。日志只过滤展示副本中的机器用量字段，内部记录保持完整；认证用的 API Token 配置不受影响。

## 验收与边界

新增离线截图用例明确区分“下腹是身体部分”和“某类评价是自我评价的下位”。教学情境给出下腹胀、尿意、暂停发言、如厕及有限的自我评价；认识根据仅支持此情境中的判断。另用“同一时段的一项自我评价”和“可包含先后变化的生活片段”两个论域演示：前者中不相容的判断，不能直接等同于后者中不能先后出现。

测试覆盖协议、原文定位、展开新旧连线、具体经验、圈区域、未知关系的局部绘制、持久保存与重新打开、失败不覆盖、恢复版本、只重试保存、共同分析入口、用户反馈重试、历史零自动请求及窄屏大字显示。保留王阳明、隆冬与夏天、时间线、比较、功能关闭与现有模块回归。页面预览标明离线教学模型，不能冒充真实模型输出。

真实模型验收新增 J：用户截图原句及相应核对要求。H（王阳明）与 I（隆冬与夏天）继续保留。用户可在设备上用当前配置模型明确运行一项，按忠实原文、概念、关系、判断、证据层级和视图逐项复核。本地结构校验不证明哲学解释正确；本轮未使用用户密钥进行付费模型调用，因此不把工程测试通过声称为真实模型的语义质量已经通过。
