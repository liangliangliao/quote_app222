# 足下一致行动 · 认知失调系统 V6 升级说明

本版在 V5 多价值选择基础上继续增强，重点从“文本式多价值关联”升级为“可统计、可追踪的价值—证据强关联”，并补充多价值协同/冲突扫描与系统闭环转化看板。

## 1. 价值—证据强关联表

新增本地表：

- `cc_evidence_value_links`

字段：

- `evidence_id`
- `value_id`
- `value_label`
- `relation_type`：`selected` 或 `inferred`
- `created_at_ms`

保存行动证据后，系统会把当前选择的多个价值写入关系表；如果没有显式选择价值，则根据当前价值上下文、AI 返回内容和价值档案做弱推断，写入 `inferred` 关系。

## 2. 多价值协同/冲突扫描

价值罗盘中选择两个或多个价值后，新增：

- “扫描协同/冲突”

会输出：

- 多价值组合
- 共同身份方向
- 协同点
- 可能冲突与护栏
- 可组合的最小行动
- 已有证据数量
- 1 美元行动原则

该功能用于帮助用户处理“成长 + 健康”“责任 + 自由”“学习 + 创造”等多价值组合，而不是一次只能围绕单一价值行动。

## 3. 证据账本统计改用强关联优先

身份证据账本、价值靠近 Top3、价值罗盘每个价值下的证据统计，优先使用 `cc_evidence_value_links` 强关联数据；旧记录没有关系表时，仍会回退到文本匹配，避免历史数据失效。

## 4. 证据卡展示强关联价值

每条证据如果有价值关系，会显示：

- `价值强关联 xxx`

帮助用户区分“AI 文本里提到的价值”和“用户当时真正选择并绑定的价值”。

## 5. 系统闭环转化看板

价值一致性报告页新增“系统闭环转化”卡片，展示：

- 最近 AI 方案数
- 已沉淀为证据的方案数
- session → evidence 转化率
- 有 session 链路的证据数量
- Todo / 问题树来源证据数量

目的不是鼓励 AI 多生成方案，而是鼓励方案真正进入行动、留下证据、回到 Todo / 问题树 / 报告继续迭代。

## 6. 兼容性

本版保留 V5 的多价值选择、Todo / 问题树双向回写、报告生成下一步行动等功能。旧数据不会丢失；没有强关联的旧证据仍通过文本匹配参与统计。
