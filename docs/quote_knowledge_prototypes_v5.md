# 名言统一分类与原型界面 v5

基线：PR #202 / `34dff5d2ec835f5edf153a7027d4f2a6d0b3f5de`。不包含独立的 PR #203。

## 使用方式

在设置中开启“叔本华认知风格”，进入历史 → 关系图。分类服务独立于这个界面开关：手动新增、AI 自动获取、CSV 导入，以及内容修改，都会持久化待归类任务。沿用现有全局文字 AI 配置。

关系图按全库分类统计，包含下位类别并按名言记录去重；不受列表当前载入的100条限制。主题气泡可选择，双击可进入下位主题，双指缩放和平移。全部类别入口支持搜索，分类树可逐层展开。关联名言卡片可打开原文、长按调整分类、点击加号选择比较。

首次打开仅用本地原主题和可识别的主题词建立“初分”，不会自动发送历史名言。历史 → 关系图 → 分类管理 → “一键分批整理旧记录”启动旧记录的语义整理；可暂停，进程退出后保留队列，下次前台运行时续跑。暂停时正在处理的一条会完成。未配置模型、离线和失败任务保留初分并延后重试，也可手动重试。

分类管理可建立根类别或下位类别、调整层级、查看待复核/失败记录、核对归类的原句依据，以及手动选择名言类别。人工归类不会被旧记录整理覆盖；修改原句内容后须重新归类。

比较页面呈现两张作者头像/原句卡片、共同点/差异点/决定性差异/各自的分析四个页签、关系图及判断目的。点按卡片可核对完整原文与出处，目的或情境变化会重新请求对应分析；已有缓存按原有规则复用。可展开“概念与依据”查看句内和跨句概念、共相与殊相、四重根据。没有充分外延依据时使用判断图，保留具体差异和缺口。共同点页突出交集，差异页突出独有范围；决定性差异由材料和目的分析，不任意指定某一侧。

## 数据与业务接口

`lib/quote_knowledge` 是应用本地 SQLite 的共享数据业务层，未新增外部服务器。新增 `qk_` 表和 quotes INSERT/UPDATE/DELETE 触发器以幂等方式安装。原名言正文、出处、通知状态与既有认识注释不改写。

- `QuoteKnowledgeRepository.snapshot(query:)`：全库类别、含下位类的去重数量、带类型的网络边、队列统计。
- `categories()` / `createCategory()` / `moveCategory()`：稳定类别身份、父子层级、同一父类中的名称/别名去重；禁止循环。
- `quotesForCategory(id, offset:, limit:, query:)`：分类子树下的名言，支持分页；空 ID 返回全库。
- `assignments()` / `assignManually()` / `reviewQueue()`：归类与原文依据、人工调整及待复核队列。
- `indexedMatches()`：其他页面按类别/别名及下位类查询；已接入 `QuoteConceptCatalog` 的相关名言查询。
- `relationEvidence()`：语义关系的原文摘录和解释。
- `QuoteKnowledgeWorker.drain()`：有租约的顺序任务处理。前台持续分批运行；定时 AI 获取在保存和通知后尽力处理一条，失败不影响通知。

模型先复用候选类别，有必要时创建定义清楚的新类；允许同一句归入多个主题。每项归类及语义关系须包含逐字原文证据和解释，返回格式、引用、关系类型及循环均校验；失败不写入部分结果。更新/删除原句、人工调整或任务租约变化后，迟到结果不能覆盖当前数据。无模型或失败仅保留明确标记的主题初分。异常信息不存储供应商错误原文。

类别树表达主题范围。网络边区分下位主题、相关概念、对照、条件主张、因果主张与共同收录；共同收录不构成概念外延包含的证据。自动语义归类仍是可复核的模型判断，原句引用检查不能保证解释绝对正确。

物理洗牌和恢复顺序会重新安装触发器。无 UID 的旧记录在物理重排前补充稳定 UID，并同步索引键，避免变动的行 ID 使分类指向另一条记录。

## 验证与预览

`quote_knowledge_test.dart` 验证入库触发器、层级/别名复用、人工分类、旧记录暂停续跑、无模型重试、租约恢复、迟到结果隔离、删除清理、全库分页去重、跨页面复用与重排兼容。

`quote_knowledge_widgets_test.dart` 使用真实 HistoryPage、比较组件和 SQLite，验证全库星图、分类树、缩放、卡片选择、比较页签、320px/双倍字体及减少动画。图像输出在 `build/quote-knowledge-preview`。名言库数量、分类与比较分析使用可重复的验收样例，文字模型为模拟响应；不代表真实供应商的解释质量或已完成 Android 真机验收。

人工验收建议：新增一条涉及已有主题的名言，检查自动收录；新增一个未覆盖的主题，检查新类别及定义；从管理中启动/暂停旧记录整理；编辑原句后检查重新归类；搜索一个第100条之后才出现的主题；比较两句名言并切换判断目的与情境，检查结果及缓存不会串用。
