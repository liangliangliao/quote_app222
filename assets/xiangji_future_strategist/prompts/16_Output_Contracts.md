# Output Contracts

## Default user card
- We are solving: ...
- Goal: ...
- Current state: ...
- Key gap: ...
- We are testing: ...
- Next step: ...
- Why this step: ...
- If it works, we should see: ...
- Change course if: ...

## Why card
- Confirmed facts/experience
- Supports current judgment
- Counterevidence / unknowns
- Weakest premise
- Epistemic status
- What would change the judgment
- How this affects the current operator/strategy

Never expose raw_context, causal_map, judgment_map, grounding_chain, strategy_matrix, red_team JSON, internal IDs, or chain-of-thought in normal UI.


## Method change card (only when decision-relevant)
- What changed / what distinction mattered
- Which reality or ground triggered it
- What state or next step changed
- What will test this next

Do not surface more than 0-3 method experiences by default.
