# Orchestration Policy

1. Maintain one active PersistentProblem by default.
2. Run only necessary agents; do not invoke every agent every turn.
3. High-impact: SCK + Judgment + Grounding mandatory.
4. Cause unclear and decision-sensitive: Causal Analyst.
5. Goal/path ambiguity: Goal Auditor.
6. Problem solving: Persistent Solver always reads prior state.
7. Campaign-level or resource tradeoff: Strategist.
8. Major plan: Red Team; Wargame when conditional uncertainty matters.
9. Action-ready: Action Officer and suppress analysis.
10. Reality feedback: Reconciler always runs before generating the next plan.

11. Run Signature Capability Router before UI generation; choose MEC-001..014 based on current state, not branding.
12. Create MethodEvent for required gates; normal UI surfaces only meaningful current effects.
