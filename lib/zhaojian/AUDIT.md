# 照见（Zhaojian）模块审计 v1

基线：`origin/codex/contextual-action-forecast-v3-20261008@641b0d17`（拉取时仓库里提交时间最新的分支；`main@5405855d` 是它的祖先）。

## 这一版做了什么

web 原型（叔本华「性格 × 动机」因果链）的**核心闭环**，作为独立模块接进「发现」页：

| 功能 | 位置 |
|---|---|
| 写下选择与选项、重要度（小/中/大） | 选择 · 第 1 步 |
| 动机补全：内置 61 条（12 类，每条带「画面」）；AI 补全约 60 条 | 选择 · 第 2 步 |
| 前 5 动机推荐：逐个打分（拉力 0–4）+ 置信度 + 常漏类别加成，每类最多 2 个；无引擎时规则推荐 | 选择 · 体验卡顶部 |
| 体验卡：分量 0–5、拉向 A/B/两边、想要/害怕、想象画面标签（含「最坏的一刻」） | 选择 · 第 3 步 |
| 动机天平（抽象 vs 直观）、勒温/米勒四种冲突诊断、想象不对称提醒 | 选择 · 第 4 步 |
| 封存预测：押注筹码、「两边都有可能」自由感、等待条件、预计的决定方式（詹姆斯） | 选择 · 第 5 步 |
| 未开的牌：现场速查卡、开牌、翻牌仪式、自知分、旁观者回放、「天平漏了动机」登记 | 未开的牌 |
| 行为记录：事后反应、思虑过/冲动、是否典型、身体信号、表达了哪条主线 | 行为记录 |
| 主线与假设：支持/反驳计数，阈值判定（≥3 次且≥2 倍；≥2 次且更多反驳） | 主线与假设 |
| 成长回顾：自知分与命中率（早期→近期）、冲突时谁胜出（按重要度拆分）、自由感与可预测性、想象深度有用吗、反应与身体信号、常漏的动机 | 成长回顾 |

## 没做（下一阶段）

行为考古与人生分期、证据分级与 AI 深度分析、一致度与难度评估、AI 生成候选选项并取前 5、
改变引擎与计划复盘、认知重构（CBT 式四步）、手段与欲求一致性检查、信念「汇票」检查、
假设行动（as-if）实验、如果—那么签名、目标链、一条线与接力、放弃拆分器、路径探测、
愿望漏斗、反宿命论提示、控制圈、数据导出。

**决策引擎**（宿主层 `lib/zhaojian_host/`，模块本体不碰网络和密钥）：

- 打分优先用真实的 **JEV（System One）**：复用 `EvidenceGrowthJev` 和「证据成长」里已启用、已配置的密钥
  （`GrowthJevAccess.key`）；每个候选一个独立的 score 问题，每批 12 题，键名 `factor_m<下标>`
  （客户端对 `factor_` 开头的可选权重题遇到非法答案会跳过而不是整批失败）。
- JEV 不可用（没启用、没密钥、限流、响应不合规、不足一半的候选有分数）→ 回落到通用大模型按决策引擎格式的**模拟**打分
  （`ZhaojianAiOracle`，界面标明不是真实的 Decisions API 或 JEV）→ 再不行用规则推荐。
- 动机补全只能由文字引擎（AI）做；JEV 不生成文字。
- 隐私：任何会把题面或动机文字发给外部服务的引擎，界面在点击前披露（`ZhaojianOracle.sendsData`）。
- **没做**：OpenAI Decisions API 的接入（格式相同，可再写一个 `ZhaojianOracle` 实现；密钥与启用开关需要新的设置入口）。
- **没验证**：中文输入下 JEV 的打分质量（据公开评测，它对英文最强）；指令用英文，题面和动机文字保持中文原文。

## 与已有模块的关系

仓库里已有意志之镜（will_mirror）、信念导师（belief_mentor）、知行树（zhixing_tree）、
证据成长（evidence_growth，含 JEV 预测）。照见**不修改、不依赖**它们：
独立表（`z_` 前缀）、独立路由、独立入口卡片。内容上有重叠（都用到叔本华或知行合一），
差异在于照见的主线是「封存预测—开牌—用行为证据检验对自己的认识」，其余模块不做这一闭环。

## 集成契约（与火种一致）

- 模块目录 `lib/zhaojian/`：除 `flutter`、`sqflite` 外零外部依赖；不自己开库，不引用 `AppDatabase`。
- 宿主装配层 `lib/zhaojian_host/`：等库、注入引擎（JEV → AI 模拟 → 规则推荐）。
- `lib/data/db.dart`：`version` 35→36；`onCreate` 调 `ZhaojianSchema.createAll`，`onUpgrade` 调 `ZhaojianSchema.migrate`（均幂等）。
- `lib/pages/discover_page.dart`：新增入口卡片与 `_openZhaojianFromDiscover`。
- 隐私：所有数据只在本机 SQLite；仅当用户点「让 AI 补全」或「为全部动机打分」时，题面和动机文字发给所配置的 AI 服务。没配置或失败时全部功能可用（内置动机库 + 规则推荐）。

## 数据表（均为 `z_` 前缀，无外键）

`z_meta`、`z_decision`（含动机 JSON、预测、开牌结果）、`z_log`、`z_hyp`、`z_miss`。

## 红线与边界

不做诊断；不依据外貌、体型判断性格；身体信号只是线索；分数只是排序和对照的依据，不是结论；
筹码是虚拟的，没有随机奖励；「自由感」统计只说明行为对自己可预测，不证明决定论。
詹姆斯五种决策、勒温/米勒冲突的措辞据二手资料整理，上线前请核对原文。
